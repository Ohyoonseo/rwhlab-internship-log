## 1. 문제 설정: 키/몸무게로 "빼야 할지 쪄야 할지" 분류하기

- **입력**: 키, 몸무게 (2개 노드)
- **출력**: 1 또는 0 (이진 분류)
  - 레이블 약속: **빼야 할 사람 = 1, 쪄야 할 사람 = 0**

### 딥러닝 문제를 푸는 공통 단계 (이진 분류뿐 아니라 대부분의 딥러닝 문제에 적용됨)

1. **데이터 수집**: 여러 사람의 키, 몸무게 + 그 사람이 "빼야 하는지/쪄야 하는지"에 대한 레이블
2. **모델 구성**: 데이터를 해석할 인공신경망 모델 설계
3. **학습**: 모델을 데이터로 학습시켜 파라미터를 찾음
4. **테스트**: 학습된 모델로 처음 보는 사람도 잘 분류하는지 확인

## 2. 퍼셉트론(Perceptron): 히든 레이어 없는 가장 단순한 구조

### 구조

```
입력: X(키), Y(몸무게)
    → 웨이트 a(X에 곱), 웨이트 b(Y에 곱), 바이어스 c
    → 들 값 = aX + bY + c
    → Unit Step Function 통과
    → 출력 (0 또는 1)
```

> **퍼셉트론 = 히든 레이어 없이, Unit Step Function을 활성화 함수로 사용하는 가장 간단한 신경망**

- "학습시킨다"는 것 = **적절한 a, b, c 값을 찾는 것**

## 3. 분류 경계(Decision Boundary)가 왜 "직선(선형)"이 되는가?

### 데이터 예시

- 키-몸무게 축 그래프에 6명의 데이터를 표시
  - 키 작고 몸무게 많이 나가는 사람들 → **빼야 함 (레이블 1)**
  - 키 크고 몸무게 적은(마른) 사람들 → **쪄야 함 (레이블 0)**

### 경계선의 정체: `aX + bY + c = 0`

- 들 값(`aX+bY+c`)이 **0보다 크면 1**, 작으면 0이 출력됨 (Unit Step Function)
- **`aX + bY + c = 0`을 만족하는 지점들이 바로 "경계선"**
- 이 식을 전개하면 `y = -(a/b)x - (c/b)` 형태의 **1차 방정식(직선의 방정식)**이 됨

> **결론: 경계선은 항상 직선(1차식) 형태이며, 이를 "선형 분류(Linear Classification)"라고 부른다**

- 학습이 잘 됐다면 → 파란 그룹과 빨간 그룹을 정확히 나누는 좋은 직선(경계선)을 찾게 됨
- 학습이 잘 안 됐다면 → 두 그룹을 제대로 구별하지 못하는 이상한 직선이 나옴

## 4. 3D로 시각화하기: 입력-출력 관계는 사실 "비선형"이다

- 밑바닥 평면: 입력(키, 몸무게) 공간
- 위로 솟은 축: 출력값(0 또는 1)
- 경계선을 기준으로:
  - 경계선 위쪽 사람들 → 출력이 **1**로 **빳빳하게 계단처럼** 튀어오름
  - 경계선 아래쪽 사람들 → 출력이 **0**으로 평평하게 유지

> **놀라운 포인트**: "선형 분류"라고 부르지만, **입력과 출력 간의 관계 자체는 계단처럼 뚝 끊기는 비선형 함수**임
> - "선형/비선형"이라는 용어는 **분류 경계선의 모양(직선인지 아닌지)**을 기준으로 붙이는 것이지, 입력-출력 함수 자체의 선형성을 말하는 게 아님

## 5. Unit Step Function의 두 가지 문제점

### 문제 ①: 미분이 불가능하다

- 계단 함수는 경계 지점에서 값이 뚝 끊기기 때문에 **미분이 불가능**함
- 그라디언트 디센트를 사용할 수 없게 됨

### 문제 ②: 너무 빡빡하게(극단적으로) 분류한다

> **비유: 헬스장이 너무 빡빡함**
> - 적정 몸무게에서 살짝(0.001kg)만 넘어가도 "당장 뛰어!"
> - 살짝만 못 미쳐도 "당장 치킨 피자 시켜서 먹어!"
> - 경계선에 아주 가깝게 있든 멀리 있든, Unit Step Function 입장에서는 **완전히 동일하게 극단적인 0 또는 1**만 출력함 — 정도(degree)를 표현할 수 없음

### 결정적 문제: "어떤 경계선이 더 합리적인지" 구별을 못함

- 예시: 완전히 극단적인 사람들(초고도비만 vs 아사 직전)만 모아놓은 데이터에서, 두 개의 후보 경계선(1번, 2번)이 있다고 하자
  - 1번 경계선: 데이터에서 여유 있게 떨어진, 직관적으로 더 합리적인 경계선
  - 2번 경계선: 데이터 바로 옆에 아슬아슬하게 붙어있는 경계선
- **Unit Step Function 기준으로는 1번도 100점, 2번도 100점** — 둘 다 완벽하게 분류하기 때문에 구별이 안 됨
- 하지만 상식적으로는 **1번이 더 좋은 경계선**임 (더 확실하고 안정적인 구분)

## 6. 해결책: 시그모이드 (Sigmoid)

> **Unit Step Function을 부드럽게 편(smooth) 것이 시그모이드**

### 시그모이드 함수의 성질

```
σ(x) = 1 / (1 + e^(-x))
```

- `x = 0` 대입 → `σ(0) = 0.5`
- `x → +∞` → `σ(x) → 1`
- `x → -∞` → `σ(x) → 0`

- 전 구간에서 **매끄럽고 미분 가능**함

### 시그모이드가 해결하는 두 가지 문제

| 문제 | 시그모이드의 해결 |
|---|---|
| 미분 불가능 | 전 구간에서 매끄럽게 미분 가능 → **그라디언트 디센트 사용 가능** |
| 극단적 분류 (0 또는 1만) | **0~1 사이의 연속적인 값**을 출력 → "정도"를 표현 가능 |

### 보너스: 확률/정도로 해석 가능

- 출력값이 0.55라면 → "빼야 하긴 하는데, 그렇게 심각하지는 않다"는 **정도**의 의미로 해석 가능
- 또는 "빼야 할 확률이 55%"라는 **확률**로도 해석 가능

### 3D 그래프로 보면?

- 경계선(0.5 지점)의 위치 자체는 Unit Step Function과 동일함
- 하지만 경계선을 지나갈 때 **뚝 끊기지 않고, 양탄자처럼 부드럽게 0에서 1로 이어지는 곡면**이 그려짐

---

## 7. 시그모이드의 또 다른 장점: 더 "합리적인" 경계선을 찾아준다

### 앞서 든 예시(1번 vs 2번 경계선)를 시그모이드로 다시 보면

- **2번 경계선(데이터에 아슬아슬하게 붙은 경계선)을 사용하면**:
  - 레이블이 0이어야 할 사람이 시그모이드 출력 0.45 정도로 나옴 (0에서 멀리 떨어짐)
  - 레이블이 1이어야 할 사람이 시그모이드 출력 0.5 정도로 나옴 (1에서 한참 멂)
  - → 이 경우 **로스(오차)가 크게 계산됨**
- **1번 경계선(데이터에서 여유 있게 떨어진 경계선)을 사용하면**:
  - 레이블이 1인 사람들은 최대한 1에 가깝게, 레이블이 0인 사람들은 최대한 0에 가깝게 출력됨
  - → **로스가 더 작음**

> **결론: 시그모이드를 쓰면, 그냥 "분류만 맞으면 만점"이 아니라 "얼마나 확신을 갖고 맞췄는지"까지 반영되기 때문에, 결과적으로 더 합리적이고 안정적인 경계선(1번)을 학습하게 됨**

- Unit Step Function은 이런 차이를 전혀 구별하지 못했지만(둘 다 만점), 시그모이드는 로스 값의 차이를 통해 **더 나은 경계선을 선택**하도록 유도함

## 8. 이번 강의 핵심 요약

- [x] **퍼셉트론**: 히든 레이어 없이 Unit Step Function을 사용하는 가장 단순한 신경망
- [x] 이진 분류에서 경계선(`aX+bY+c=0`)이 직선(1차식)이기 때문에 이를 **선형 분류**라고 부름
- [x] 단, "선형 분류"라는 이름과 별개로, **입력-출력 관계 자체는 계단 모양의 비선형 함수**임
- [x] **Unit Step Function의 두 가지 문제**: ① 미분 불가능, ② 정도를 표현하지 못하고 극단적인 0/1로만 분류
- [x] **시그모이드**: Unit Step Function을 부드럽게 만든 활성화 함수 — 전 구간 미분 가능 + 0~1 사이 연속값 출력
- [x] 시그모이드의 출력은 **확률 또는 정도**로 해석 가능
- [x] 시그모이드는 로스 값을 통해 **더 합리적이고 안정적인 분류 경계선**을 학습하도록 유도함 (Unit Step은 이런 차이를 구별하지 못함)
