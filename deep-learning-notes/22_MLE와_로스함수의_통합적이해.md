# 22강. 최대우도추정(MLE)으로 통합해서 이해하는 로스 함수 (레벨 3, 심화)

> 딥러닝 강의 22강 정리 노트 — 강사가 "모든 강의 통틀어 가장 어려운 내용"이라고 언급한 파트

## 1. 핵심 결론 먼저: MSE와 BCE는 사실 "같은 뿌리"에서 나왔다

> **MSE와 BCE는 완전히 다른 두 개의 로스가 아니라, 둘 다 "라이클리후드(Likelihood)를 최대화하는 방법"의 한 형태일 뿐이다**

- 로스를 어떻게 정의하느냐는 결국 **"레이블이 어떤 확률분포를 따른다고 가정하느냐"**의 차이일 뿐
- 이 관점을 이해하면, 나중에 새로운 로스 함수를 배워도 "얘는 무슨 분포를 가정한 거지?"만 생각하면 됨

---

## 2. 조건부 확률 vs 라이클리후드(Likelihood) — 핵심 차이

### 예시: 주머니 2개

```
A 주머니: 흰공 1개, 검은공 1개
B 주머니: 흰공 2개, 검은공 1개
```

### 조건부 확률 (Conditional Probability)

> **"주머니(조건)가 정해져 있을 때, 특정 공이 나올 확률"** — 세로로 읽는 것

| | 흰공 | 검은공 |
|---|---|---|
| A 주머니를 선택했을 때 | 1/2 | 1/2 |
| B 주머니를 선택했을 때 | 2/3 | 1/3 |

- 조건(주머니)을 고정하고, 그 안에서 결과(공 색깔)의 확률을 봄

### 라이클리후드 (Likelihood)

> **"결과(공 색깔)가 이미 정해져 있을 때, 그것을 만들어낸 조건(주머니)이 무엇인지"를 가로로 읽는 것**

- 예: "흰공이 나왔다"는 결과를 고정하고, `A 주머니였을 때의 확률(1/2)`과 `B 주머니였을 때의 확률(2/3)`을 비교
- **중요한 차이**: 라이클리후드는 확률값이긴 하지만, **합이 1이 되지 않음** → 확률분포가 아님 (조건부 확률표를 가로로 읽으면 합이 1이 아니게 되는 것과 같은 원리)

---

## 3. 라이클리후드로 "숨겨진 것"을 추정하기 (MLE, Maximum Likelihood Estimation)

### 퀴즈: 공을 하나 꺼냈는데 흰공이 나왔다면, A 주머니에서 꺼냈을까 B 주머니에서 꺼냈을까?

- **A 주머니였을 확률(라이클리후드) = 1/2**
- **B 주머니였을 확률(라이클리후드) = 2/3**
- → **B 주머니에서 꺼냈을 가능성이 더 크다고 추정**

> **이렇게 "라이클리후드 값이 가장 크게 나오는 쪽"으로 뒤에 숨겨진 것을 추정하는 방법이 바로 최대우도추정 (Maximum Likelihood Estimation, MLE)**

### 핵심 구조: "메저먼트(측정값)"를 보고 "벽 뒤에 숨겨진 것"을 알아낸다

- **메저먼트(Measurement)**: 이미 관측된 것, 눈에 보이는 것 (예: 꺼낸 공의 색깔)
- **벽 뒤에 있는 것**: 직접 볼 수 없지만 알고 싶은 것 (예: 어느 주머니에서 꺼냈는지)

### 일상 속 비유: 썸녀의 카톡 답장 빈도

- **우리가 알고 싶은 것(벽 뒤의 것)**: 그녀가 나에게 마음이 있는지 없는지
- **우리가 볼 수 있는 것(메저먼트)**: 답장 빈도 (예: 28시간에 한 번)
- 질문: "마음이 있을 때 28시간마다 답장할 확률"과 "마음이 없을 때 28시간마다 답장할 확률" 중 뭐가 더 클까?
- → 이 라이클리후드 비교를 통해 "마음이 없는 쪽의 확률이 더 크다"는 결론에 도달 → **"접어야겠다"**

> 이런 식으로, 실생활에서도 이미 무의식적으로 MLE 방식의 추론을 하고 있다는 것

## 4. 이진 분류에 MLE 적용하기

### 우리가 알고 싶은 것 = 웨이트(Weight)

- 이진 분류 상황: **"레이블 y1이 이렇게 나온 것을 보니, 웨이트가 어떤 값이었을 가능성이 가장 클까?"**
- 여기서:
  - **메저먼트(눈에 보이는 것)** = 레이블 y1 (강아지=1인지 고양이=0인지, 이미 정해진 정답)
  - **벽 뒤에 있는 것(알고 싶은 것)** = 웨이트 (몰라서 찾아야 하는 값)

> **`P(y1 | 웨이트)`를 웨이트를 바꿔가며 관찰하는 것 = 라이클리후드**
> **이 라이클리후드를 최대화하는 웨이트를 찾는 것 = 학습**

- 즉, "X1이 들어갔을 때 y1과 비슷한 값이 출력되게 학습하자"는 것을, 좀 더 엄밀한 확률적 관점으로 보면 "**X1이 들어갔을 때 y1이 나올 확률을 최대화하는 웨이트를 찾는다**"로 재해석할 수 있음

---

## 5. 이진 분류의 라이클리후드 = 베르누이 분포(Bernoulli Distribution)

### 베르누이 분포란?

- 결과가 **딱 두 가지(0 또는 1)**뿐인 분포 (동전 던지기와 같은 개념)
- 앞면(1) 나올 확률: `Q`, 뒷면(0) 나올 확률: `1-Q`

### 수식으로 표현

```
P(y) = Q^y × (1-Q)^(1-y)
```

- `y=1` 대입 → `Q`
- `y=0` 대입 → `1-Q`

> **이 수식이 바로 "베르누이 분포를 확률 함수로 나타낸 것"** — 그리고 이 수식은 우리가 이전 강의에서 BCE를 유도할 때 이미 봤던 바로 그 수식임!

### 결론: BCE = 베르누이 분포를 가정한 NLL(Negative Log-Likelihood)

```
과정: 라이클리후드(베르누이 분포식) 세움
      → 여러 데이터는 곱(독립시행)
      → 로그를 취해서 곱을 합으로 변환 (언더플로우 방지)
      → 마이너스를 붙여서 "최대화 문제"를 "최소화(로스) 문제"로 전환
      → 이렇게 만들어진 것이 NLL (Negative Log-Likelihood)
      → 이것이 곧 Binary Cross Entropy Loss
```

> **BCE는 "레이블(y)이 베르누이 분포를 따른다"고 가정하고, 신경망 출력(Q)이 그 분포의 파라미터를 잘 맞추도록 학습시킨 것**

---

## 6. 같은 원리로 MSE 유도하기 — 가우시안(정규) 분포를 가정한 경우

### 만약 레이블(y)이 "가우시안 분포(정규분포)"를 따른다고 가정한다면?

- 가우시안 분포의 확률밀도함수(고등학교에서 배운 정규분포 공식)를 라이클리후드로 세움
- 여기서 **신경망의 출력이 이 가우시안 분포의 "평균(mean)"을 잘 예측하도록** 학습시킨다고 가정
- 여기에 로그를 취하고 마이너스를 붙여서(NLL) 전개해보면:

```
NLL 전개 결과 = (상수항) + (1/2σ²) × (y - 예측값)²
```

- 상수항들을 무시하고 핵심만 남기면 → **`(y - 예측값)²`** 형태
- **이것이 바로 MSE(Mean Squared Error)!**

> **결론: MSE는 "레이블(y)이 가우시안 분포를 따른다"고 가정하고, 신경망 출력이 그 분포의 평균을 잘 예측하도록 학습시킨 것**

### 왜 이 관점이 유용한가?

- 기존에는 "그냥 MSE 써볼까, BCE 써볼까"를 그래프 개형만 보고 판단할 수밖에 없었음
- 하지만 이 관점을 알면: **"내 데이터(레이블)가 실제로 어떤 분포를 따르는가?"**를 먼저 생각해서, 그에 맞는 로스 함수를 논리적 근거를 가지고 선택할 수 있음
- **이진 분류의 레이블은 0 또는 1, 딱 두 값만 가능** → 마이너스 무한대부터 무한대까지 값을 가지는 가우시안 분포보다는, **0과 1만 존재하는 베르누이 분포가 훨씬 더 적절한 가정**
- → 그래서 이진 분류에는 MSE보다 BCE가 더 잘 맞는 것 (이전 강의에서 본 "더 민감함", "컨벡스함"이라는 장점들도 사실 이 "가정의 적절성" 차이에서 비롯된 결과)

---

## 7. 참고: MAE는 라플라시안(Laplacian) 분포에서 나온다

- 같은 방식으로 MAE(Mean Absolute Error, 절댓값 로스)를 거꾸로 추적해서 올라가보면
- **레이블이 "라플라시안 분포"를 따른다고 가정**하고, 그 분포의 평균(위치 파라미터)을 신경망이 잘 예측하도록 NLL을 세운 것과 동일함

---

## 8. 최종 통합: 모든 로스는 결국 "NLL" 하나로 설명된다

### 큰 그림 정리

```
뿌리: 라이클리후드(Likelihood) = P(레이블 | 웨이트)
   ↓ (어떤 분포를 가정하느냐에 따라 줄기가 갈라짐)
   
   가우시안 분포 가정  → NLL 전개 → MSE
   라플라시안 분포 가정 → NLL 전개 → MAE
   베르누이 분포 가정   → NLL 전개 → Binary Cross Entropy
   멀티누이(카테고리) 분포 가정 → NLL 전개 → Cross Entropy (다음 강의 예정)
```

> **딥러닝에서 배우는 다양한 로스 함수들(MSE, MAE, BCE, Cross Entropy 등)은 사실 전부 "같은 원리(NLL)"에서 출발했고, 어떤 확률분포를 가정했는지만 다를 뿐이다**

### 일반화된 학습 수식

```
인공신경망 = F_W(입력)  (웨이트 W를 가진 함수)

목표: P(y | W)를 최대화하는 W를 찾는다 (라이클리후드 최대화, MLE)

데이터가 여러 개면: 곱(독립시행) → 로그(합으로 변환) → 마이너스(최소화 문제로 전환)
→ 이것이 바로 NLL이며, 이것이 곧 "로스"가 된다
```

> **결국 딥러닝의 "학습"이라는 것은 전부 "웨이트에 대한 MLE(최대우도추정)를 하는 것"으로 하나의 틀 안에서 설명 가능하다**

### 이 관점이 주는 실질적 이점

- 새로운 로스 함수를 마주쳤을 때, **"이건 어떤 분포를 가정한 거지?"**라는 질문 하나로 그 로스의 성격을 파악할 수 있음
- 내 문제 상황에서 레이블이 실제로 어떤 분포를 따를지 먼저 고민해보고, **그에 맞는 로스 함수를 논리적 근거를 가지고 선택**할 수 있게 됨

## 9. 이번 강의 핵심 요약

- [x] **조건부 확률**(조건 고정, 결과를 봄)과 **라이클리후드**(결과 고정, 조건을 바꿔가며 봄)는 다른 개념 — 라이클리후드는 확률값이지만 합이 1이 아니므로 확률분포는 아님
- [x] **MLE(최대우도추정)**: 라이클리후드가 가장 커지는 "숨겨진 값"을 정답으로 추정하는 방법
- [x] 이진 분류에서 "벽 뒤에 숨겨진 것" = **웨이트**, "메저먼트(관측값)" = **레이블**
- [x] 이진 분류의 라이클리후드는 **베르누이 분포**로 표현되며, 이를 NLL(마이너스 로그 라이클리후드)로 바꾼 것이 **BCE**
- [x] **레이블이 가우시안 분포를 따른다고 가정**하면 NLL 전개 결과가 **MSE**가 됨
- [x] **레이블이 라플라시안 분포를 따른다고 가정**하면 NLL 전개 결과가 **MAE**가 됨
- [x] 이진 분류는 레이블이 0/1 두 값만 가지므로, 무한한 범위를 가정하는 가우시안보다 **베르누이 분포가 훨씬 적절한 가정** → 그래서 BCE가 더 좋은 선택
- [x] **결론: MSE, MAE, BCE, Cross Entropy는 모두 같은 뿌리(라이클리후드의 NLL)에서 나왔으며, 어떤 확률분포를 가정했는지에 따라 다른 형태로 전개된 것뿐이다**

---

## 용어 정리

| 용어 | 의미 |
|---|---|
| 조건부 확률 (Conditional Probability) | 조건이 주어졌을 때 결과의 확률 (합이 1이 되는 확률분포) |
| 라이클리후드 (Likelihood) | 결과가 주어졌을 때, 그 결과를 만든 조건(파라미터)에 대한 확률값 — 합이 1이 아님, 확률분포가 아님 |
| MLE (Maximum Likelihood Estimation, 최대우도추정) | 라이클리후드를 최대화하는 파라미터(숨겨진 값)를 찾는 추정 방법 |
| NLL (Negative Log-Likelihood) | 라이클리후드에 로그를 취하고 마이너스를 붙인 것 — 로스 함수로 사용 |
| 베르누이 분포 (Bernoulli Distribution) | 결과가 두 가지(0 또는 1)뿐인 분포 — BCE의 근간 |
| 가우시안 분포 (Gaussian Distribution) | 정규분포 — MSE의 근간 |
| 라플라시안 분포 (Laplacian Distribution) | 뾰족한 형태의 분포 — MAE의 근간 |
