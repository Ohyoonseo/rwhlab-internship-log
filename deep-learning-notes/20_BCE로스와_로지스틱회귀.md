# 20강. 이진 분류 실전: Binary Cross Entropy (BCE) 로스

## 1. 강아지/고양이 분류 문제로 파라미터 개수 세어보기

### 설정

- 입력: `3×100×100` 사진 (RGB 3채널, 100×100 픽셀)
- 히든 레이어 없이 곧바로 출력층(Fully Connected)으로 연결
- 활성화 함수: 시그모이드 (0~1 사이 출력)

### 파라미터 개수 계산

```
전체 픽셀 수 = 3 × 100 × 100 = 30,000개
웨이트 = 30,000개 (모든 픽셀이 출력 노드 1개와 연결)
바이어스 = 1개
총 파라미터 = 30,001개
```

> **그라디언트의 길이도 30,001** — 결국 우리가 알아내야 할 것은 이 3만 개가 넘는 웨이트와 1개의 바이어스

### 다시 확인하는 딥러닝 수식의 뼈대

```
(k+1번째 웨이트·바이어스) = (k번째 웨이트·바이어스) - α × 그라디언트
```

- 이 수식 자체는 이미 다 배운 내용 (GD/SGD/미니배치, 모멘텀/RMSProp/Adam 등은 전부 "그라디언트를 어떻게 구하고 활용하는가"의 차이일 뿐)
- **결국 이 수식에서 우리가 새로 정의해야 하는 것은 "로스(Loss)" 하나뿐**
- 지금까지는 MSE(회귀용 로스)만 배웠는데, 이번엔 **분류에 더 적합한 크로스 엔트로피(Cross Entropy)** 로스를 배움

## 2. 로스를 설계하는 아이디어: "출력의 의미를 내가 정할 수 있다"

### 핵심 발상

- 신경망 출력을 그냥 "0~1 사이의 어떤 값"이 아니라, **"강아지일 확률"**이라는 의미로 만들고 싶음
- 어떻게? → **로스를 그렇게 정의하면 됨**
- 아주 단순한 원칙: **강아지 사진을 넣었는데 출력이 0에 가까울수록 더 크게 혼낸다(로스를 키운다)**
- 그러면 모델은 로스를 줄이려고 자연스럽게 강아지 사진에 대해 출력을 1에 가깝게 만들려고 함

### 변수 정의

- 신경망 출력: `Q`
- 정답 레이블: `y` (강아지=1, 고양이=0)

---

## 3. 로스 설계 과정 ①: "확률을 그냥 키우면 된다"

### 발상의 단순화

- "Q가 1에 가깝게 나오도록 하자"라는 건 복잡하게 생각할 필요 없이 그냥 **"Q를 최대한 키우자(Maximize Q)"**로 충분함
- 왜 이렇게 단순화해도 되는가?
  - 우리가 조절할 수 있는 건 웨이트와 바이어스뿐인데, **시그모이드를 썼기 때문에 출력은 절대 0~1 범위를 벗어날 수 없음**
  - 즉 아무리 Q를 키워봐야 1보다 커질 수 없으므로, "그냥 키우자"가 곧 "1에 가깝게 만들자"와 동일한 효과를 냄

### 조건문을 하나의 수식으로 통합

```
IF 강아지 사진(y=1): Maximize Q
IF 고양이 사진(y=0): Maximize (1-Q)
```

- Maximize Q ↔ Minimize (-Q)는 완전히 동치 (부호만 바꾼 것 — 우리 관심사는 값 자체가 아니라 웨이트·바이어스이므로 상관없음)
- `-Q` 대신 `1-Q`를 최대화하는 것으로 바꿔 쓰면(+1을 붙이면), 0~1 범위의 "확률"처럼 해석 가능해짐

### 한 줄 수식으로 합치기

```
Maximize:  Q^y × (1-Q)^(1-y)
```

- `y=1`(강아지)일 때 대입: `Q^1 × (1-Q)^0 = Q` → Maximize Q ✅
- `y=0`(고양이)일 때 대입: `Q^0 × (1-Q)^1 = 1-Q` → Maximize (1-Q) ✅

> **이 한 줄이 바로 "해당 동물일 확률"을 나타냄** — y가 1이면 강아지 확률, y가 0이면 고양이 확률

## 4. 로스 설계 과정 ②: 여러 장의 사진을 동시에 고려하기

### 문제: 확률을 계속 곱하면 언더플로우 발생

- 미니배치로 여러 장(예: 배치 사이즈 64)을 학습할 때는, 각 사진의 "해당 동물일 확률"을 **모두 곱해서** 함께 최대화해야 함 (독립 시행이므로 곱셈)
- 하지만 0~1 사이의 확률값을 수십, 수백 개 계속 곱하면 → 결과가 급격히 0에 가까워짐
- 컴퓨터가 매우 작은 값들끼리 구별을 못하게 되는 문제 = **언더플로우(Underflow)**

### 해결책: 로그(log)를 취해서 곱셈을 덧셈으로 바꾼다

```
Maximize:  Σ [ y_n×log(Q_n) + (1-y_n)×log(1-Q_n) ]
```

- 로그를 취하면 **곱셈이 덧셈으로 변환**되어 언더플로우 문제가 해결됨
- 마지막에 마이너스(-)를 붙이면 "최대화 문제"가 "최소화(로스) 문제"로 바뀜

```
Loss = -Σ [ y_n×log(Q_n) + (1-y_n)×log(1-Q_n) ]
```

> **이것이 바로 Binary Cross Entropy Loss (BCE Loss)**

## 5. 왜 로그를 취해도(줄이는 목표가) 바뀌지 않는가? — 단조함수(Monotonic Function)의 원리

### 핵심 질문

> 원래 로스를 줄이고 싶은데, 갑자기 로그를 취해서 그걸 대신 줄여도 될까?

### 답: 로그는 단조 증가 함수이기 때문에 가능하다

- x축: 원래 로스, y축: 로그를 취한 로스 라고 그래프를 그려보면
- **로그 함수는 단조 증가(항상 우상향)** 함
- 로그를 취한 값을 아래로 당기면(줄이면) = x축에서도 왼쪽으로 당겨지는 것(원래 로스도 함께 줄어듦)과 정확히 동일한 효과
- 줄어드는 **정도(양)**는 다를 수 있지만, **방향(줄어드는 쪽으로 간다는 사실)은 항상 일치**함

### 반례로 이해하기: 단조롭지 않은 함수(예: 코사인)라면?

- 코사인 함수는 오르락내리락하기 때문에, 같은 y값(코사인 로스)이라도 실제 x값(원래 로스)이 어디인지 **모호함**
- 코사인 값을 줄이려고 했다가, 실제로는 원래 로스가 오히려 **커지는 방향**으로 갈 수도 있음
- → **단조롭지 않은 함수는 함부로 취할 수 없음**

### 참고: 값의 범위가 제한적이라면 단조롭지 않은 함수도 조건부로 쓸 수 있음

- 예: 로스 값이 항상 0~1 사이로만 제한된다면, 그 좁은 구간 안에서는 코사인 같은 함수도 (그 구간 안에서 단조롭기만 하다면) 사용 가능
- 하지만 일반적으로는 **단조 증가(또는 단조 감소) 함수**를 사용하는 것이 안전함

## 6. 심화 (Level 2): 로지스틱 회귀(Logistic Regression)로 해석하기

> 이 부분은 필수는 아니지만, 알아두면 딥러닝을 더 깊이 이해할 수 있는 내용

### 로짓(Logit)이란?

- **로짓(Logit) = 로그(Log) + 오즈(Odds)**의 준말
- **오즈(승산, Odds)**: `승리 확률 / 패배 확률` (도박 용어에서 온 개념)
- **로짓 = 오즈에 로그를 취한 값**

### 로짓과 확률(시그모이드)의 관계 유도

```
L = log( Q / (1-Q) )   ← 정의: 로짓 = log(오즈)

전개하면:
e^L = Q / (1-Q)
1/e^L = (1-Q)/Q  (양변 역수)
... 정리하면 ...

Q = 1 / (1 + e^(-L))
```

> **이 결과가 바로 시그모이드 함수!**

- 즉, **로짓(L)을 시그모이드에 통과시키면 확률(Q)을 얻을 수 있다**는 관계가 성립
- 시그모이드 통과 **직전**의 값 = 로짓(Logit), 통과 **직후**의 값 = 확률(Probability)

### 인공신경망을 다시 뜯어보기

- 신경망을 "로짓이 출력되는 신경망"까지로 범위를 좁혀서 보면:
  - 이 부분은 입력(사진)과 로짓 사이의 관계를 **Linear Activation**으로 설정한 것과 같음
  - 즉, 이 부분만 떼어놓고 보면 **선형회귀(Linear Regression) 문제를 푼 것**과 동일하게 해석 가능

### 그렇다면 시그모이드는 무엇인가? (재해석)

> **시그모이드는 인공신경망의 일부(활성화 함수)가 아니라, BCE Loss를 계산하기 위해 "로짓을 확률로 변환해주는" 도구일 뿐이라고도 볼 수 있다**

- 이런 관점에서 보면: "로짓을 만들어내는 선형회귀 문제"를 풀고, 그 로짓을 시그모이드로 확률로 바꿔서 BCE Loss를 계산하는 것 = **로지스틱 회귀(Logistic Regression)**
- "로지스틱 함수(시그모이드)를 사용한 회귀"라는 뜻에서 이런 이름이 붙음
- 흥미로운 점: **분류(Classification) 문제도 결국 회귀(Regression)의 한 갈래로 볼 수 있음** — Classification과 Regression은 뿌리가 같다는 것

## 8. 이번 강의 핵심 요약

- [x] 파라미터 개수(예: 30,001개)를 세어봐도, 결국 딥러닝 수식에서 우리가 새로 정의할 것은 **로스(Loss)** 하나뿐
- [x] 로스 설계의 핵심 아이디어: **"출력이 정답에 가까울수록 로스를 작게" → "정답 클래스일 확률을 그냥 최대화"**로 단순화
- [x] `y=1`일 땐 Q를 최대화, `y=0`일 땐 (1-Q)를 최대화 → 한 줄 수식 `Q^y × (1-Q)^(1-y)`로 통합
- [x] 여러 데이터의 확률을 곱하면 **언더플로우** 발생 → **로그**를 취해 곱셈을 덧셈으로 변환
- [x] 로그를 취해도 최적화 방향이 바뀌지 않는 이유: 로그가 **단조 증가 함수**이기 때문
- [x] 최종적으로 마이너스를 붙여 **Binary Cross Entropy (BCE) Loss** 완성
- [x] (심화) **로짓(Logit) = log(오즈)**이며, 로짓을 시그모이드에 통과시키면 확률이 나옴 — 이 관계로 인해 이진 분류를 **로지스틱 회귀**라고도 부름
- [x] (심화) 이런 관점에서는 시그모이드가 활성화 함수라기보다, **로짓을 확률로 변환해 BCE Loss를 계산하기 위한 도구**로 해석 가능
- [x] 다음 강의: MSE 대신 BCE를 쓰는 이유

## 용어 정리

| 용어 | 의미 |
|---|---|
| BCE (Binary Cross Entropy) Loss | 이진 분류에서 사용하는, 정답 클래스의 확률을 최대화하는 방식의 로스 함수 |
| 언더플로우 (Underflow) | 매우 작은 값들을 계속 곱해서 컴퓨터가 구별 못 할 정도로 0에 가까워지는 문제 |
| 단조함수 (Monotonic Function) | 항상 증가하거나(단조 증가) 항상 감소하는(단조 감소) 함수 — 최적화 방향을 보존하기 위해 로그 변환에 활용됨 |
| 오즈 (Odds, 승산) | 승리 확률 ÷ 패배 확률 |
| 로짓 (Logit) | 오즈에 로그를 취한 값 — 시그모이드를 통과하면 확률이 됨 |
| 로지스틱 회귀 (Logistic Regression) | 로짓을 선형회귀로 구하고, 시그모이드로 확률로 변환해 BCE Loss로 학습하는 방식으로 해석되는 이진 분류 모델 |
