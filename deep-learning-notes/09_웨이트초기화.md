# 9강. 웨이트 초기화 (Weight Initialization)

> 딥러닝 강의 9강 정리 노트

---

## 1. 지난 시간 복습: Gradient Descent

- 웨이트/바이어스를 아무렇게나 정하고, 현재 위치에서 **로스를 줄이는 방향**으로 나아가는 것
- **그라디언트** = 길라잡이 — 로스를 가장 많이 **올리는** 방향을 가리키는 벡터
  - → 그 **반대 방향**으로 조금씩 이동
- 왜 "조금씩"? 그라디언트의 방향은 맞지만 **크기가 너무 커서**, 그대로 이동하면 오버슈팅됨
  - → **러닝레이트(0~1 사이 값)**를 곱해서 보폭을 줄임

### 비유: 현재에 충실하기
- 미래를 미리 다 계산할 수 없으니, **현재 위치에서 최선의 방향으로 한 걸음씩** 나아가는 것
- "지금 듣고 있는 수업에 집중하자"는 마인드와 비슷 — 매 순간 최선을 다해 결정하고 나아감

---

## 2. 이번 주제: 초기 웨이트(Initial Weight)는 어떻게 정할까?

- 이전에 "아무렇게나 잡으세요"라고 했지만, **진짜 아무렇게나** 잡으면 비효율적일 수 있음
- 대표적인 3가지 방식 제안자: **르쿤(LeCun)**, **카이밍(Kaiming He)**, **자비어(Xavier/Glorot)**

### 공통점
- **랜덤하게** 값을 뽑음
- **0 근처**로 잡음 (평균이 0)

### 차이점
- **분산(값이 퍼진 정도)**을 계산하는 방식이 서로 다름

---

## 3. 기본 분포 두 종류: 균등분포(U) vs 정규분포(N)

| 표기 | 의미 |
|---|---|
| **U (Uniform, 균등분포)** | 특정 구간 안에서 **모든 값이 뽑힐 확률이 동일** (평평한 사각형 모양) |
| **N (Normal, 정규분포)** | 우리가 아는 **정규분포(가우시안)** — 평균과 분산으로 모양이 완전히 결정됨, 평균 근처 값이 더 자주 뽑힘 |

- 정규분포는 평균과 분산만 정하면 분포 모양이 하나로 확정됨
- 두 분포 모두 값의 범위 자체는 무한하지만(정규분포는 이론상 -∞~∞), **분산이 같으면 "퍼진 정도"는 비슷하게 맞출 수 있음**

> 예: 균등분포 `[-3, 3]`과 정규분포(평균 0, 분산 3)는 **평균과 분산이 서로 동일**하지만, 모양은 다름 (균등분포는 평평, 정규분포는 가운데로 몰림)

---

## 4. n_in, n_out이란?

인공신경망의 한 층(layer)을 예로 들면:

- **n_in**: 그 웨이트로 **들어오는(입력되는) 노드의 개수**
- **n_out**: 그 웨이트를 통해 **나가는(출력되는) 노드의 개수**

예: 입력 노드 3개 → 출력 노드 2개로 연결되는 층의 웨이트라면
```
n_in = 3, n_out = 2
```

---

## 5. LeCun 방식

### 웨이트(W) 초기화 방식
```
U(-1/√n_in, 1/√n_in)   또는
N(0, 1/n_in)
```
- 바이어스(b)는 보통 그냥 **0**으로 초기화

### 특징
- 둘 다(균등분포 버전 / 정규분포 버전) **평균 0, 분산 1/n_in**으로 서로 동일
- **n_in만 사용**, n_out은 고려하지 않음

---

## 6. 왜 n_in을 고려해야 할까?

### 문제 상황
- 만약 n_in의 크기와 무관하게, 항상 고정된 분산(예: 0.1)으로 웨이트를 뽑는다고 가정
- n_in이 매우 크다면(예: 100개) → **웨이트를 아주 많이 곱하고 더하게 됨**
- 곱하고 더하는 항이 많아질수록 **결과 값의 분산이 점점 커짐** (통계적으로 자연스러운 현상)
- 값의 분산이 너무 커지면:
  - 활성화 함수(액티베이션)를 통과할 때 값이 **들쭉날쭉하게 폭발적으로 변함**
  - 학습이 **불안정**해짐

### 해결책
- **n_in이 클수록 웨이트 자체의 분산을 작게** 잡아서, 여러 개를 곱하고 더해도 결과 값의 분산이 적절히 유지되도록 조절
- → **분산을 n_in으로 나눠주는 방식**으로 이를 구현 (`1/n_in`)

---

## 7. Kaiming (He) 방식

```
분산 = LeCun 방식의 2배
```

### 특징
- LeCun 방식과 기본 구조는 비슷하지만, **분산을 2배로** 잡음
- 주로 **ReLU** 활성화 함수를 사용하는 신경망에서 많이 사용됨

---

## 8. Xavier (Glorot) 방식

### n_out까지 함께 고려하는 이유: 백프로파게이션(Backpropagation)

- 지금까지는 **정방향(입력 → 출력)**으로 값이 전달될 때의 분산만 고려함
- 하지만 학습 과정에는 **역방향(출력 → 입력)**으로 그라디언트를 전달하는 **백프로파게이션** 과정도 있음 (추후 강의에서 자세히 다룰 예정)
- 백프로파게이션 시에는 반대 방향으로 여러 값이 더해짐
  - 만약 **n_out이 매우 크면**, 역방향으로 전파될 때 **그라디언트가 폭발적으로 커질 수 있음**
- 즉:
  - **n_in만 고려** → 정방향(입력 → 출력)으로 갈 때는 안정적이지만, 역방향(그라디언트 계산) 시엔 n_out이 크면 불안정해질 수 있음
  - → **n_in과 n_out 둘 다 고려**해야 정방향/역방향(포워드 시그널 & 백워드 시그널) 모두 안정적으로 전파됨

### Xavier의 분산 공식
```
분산 = 1 / (n_in + n_out)
```
- LeCun 방식(`1/n_in`)보다 분모가 더 크므로 **분산이 더 작음**
- 즉, Xavier 방식은 초기값을 **더 보수적으로, 더 0 근처로** 잡음
- 주로 **시그모이드(Sigmoid), 하이퍼볼릭 탄젠트(tanh)** 계열 활성화 함수에 적합하다고 알려져 있음 (절대적인 법칙은 아니며, "베니싱 그라디언트" 문제와 관련 — 추후 강의에서 다룸)

---

## 9. 세 방식 비교 정리

| 방식 | 고려하는 값 | 분산 공식 | 주로 쓰이는 곳 |
|---|---|---|---|
| **LeCun** | n_in만 | `1/n_in` | 일반적인 경우 |
| **Kaiming (He)** | n_in만 | `2/n_in` (LeCun의 2배) | ReLU 계열 |
| **Xavier (Glorot)** | n_in + n_out | `1/(n_in + n_out)` | Sigmoid, tanh 계열 |

- 공통점: 모두 **랜덤하게, 평균 0 근처**로 초기화
- 차이점: **분산을 계산할 때 무엇을 고려하는지**가 다름

## 10. 생각해볼 문제 (강사가 낸 퀴즈, 다음 강의 예고 겸)

> 만약 모든 웨이트를 **똑같이 0으로** 초기화하면 어떤 문제가 생길까?
> 만약 모든 웨이트를 **똑같이 1로** 초기화하면 어떤 문제가 생길까? (0이 아니니까 괜찮을 것 같지만, 사실 이것도 문제)

- 이 두 경우 모두 문제가 있으며, **왜 반드시 "완전히 랜덤하게" 뿌려야 하는지**와 연결되는 질문
- 백프로파게이션 개념을 배운 후에 더 명확히 이해할 수 있음 (다음 강의 이후 예정)

## 11. 이번 강의 핵심 요약

- [x] 초기 웨이트는 **완전 무작위가 아니라, 수학적 근거가 있는 분포**에서 뽑아야 함
- [x] 균등분포(U)와 정규분포(N) 둘 다 사용 가능 (평균·분산만 같으면 통계적 성질은 유사)
- [x] **n_in**: 들어오는 노드 수, **n_out**: 나가는 노드 수
- [x] n_in이 크면 곱셈·덧셈이 많아져서 결과값의 분산이 커짐 → **웨이트 분산을 n_in에 반비례하게 조절**해서 안정화
- [x] **LeCun**: `1/n_in` 만 고려
- [x] **Kaiming(He)**: LeCun의 2배 분산, ReLU에 적합
- [x] **Xavier**: `1/(n_in+n_out)`, 백프로파게이션(역방향 전파)까지 고려해서 더 보수적인 분산, Sigmoid/tanh에 적합
- [x] 모든 웨이트를 0 또는 1로 똑같이 초기화하면 문제 발생 (다음 강의에서 이어질 내용)

## 용어 정리

| 용어 | 의미 |
|---|---|
| 웨이트 초기화 (Weight Initialization) | 학습 시작 전 웨이트의 초깃값을 설정하는 것 |
| 균등분포 (Uniform Distribution) | 구간 내 모든 값이 뽑힐 확률이 동일한 분포 |
| 정규분포 (Normal Distribution) | 평균과 분산으로 모양이 결정되는 가우시안 분포 |
| n_in | 해당 웨이트로 들어오는 노드(입력)의 개수 |
| n_out | 해당 웨이트에서 나가는 노드(출력)의 개수 |
| 백프로파게이션 (Backpropagation) | 출력 쪽에서 입력 쪽으로 그라디언트를 역전파하는 과정 (추후 강의) |
| LeCun 초기화 | n_in만 고려하는 초기화 방식 |
| Kaiming(He) 초기화 | LeCun의 2배 분산, ReLU에 적합 |
| Xavier(Glorot) 초기화 | n_in과 n_out을 모두 고려하는 초기화 방식 |
