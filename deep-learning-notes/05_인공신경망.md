# 5강. 인공신경망 (Artificial Neural Network)

> 딥러닝 강의 5강 정리 노트 — 챕터 2: 인공신경망과 선형회귀

---

## 1. 인공신경 = 우리 몸 신경을 본뜬 것

인공신경망(Artificial Neural Network)은 우리 몸의 **신경**을 인공적으로 표현한 것.

실제 신경의 기능 3단계:
1. 자극을 **전달받는다**
2. 전달할지 말지를 **정한다**
3. 자극을 **전달한다**

→ 이 세 가지 기능을 본떠서 만든 것이 **인공 신경(Artificial Neuron)**

---

## 2. 인공 신경 만들어보기: "정색 여부 판단" 예시

### 상황 설정
- 자극 두 군데에서 들어온다고 가정: **뒤통수**, **손바닥(하이파이브)**
- 각 자극의 값: 자극이 있으면 1, 없으면 0

| 상황 | 뒤통수 | 손바닥 | 정색해야 하나? |
|---|---|---|---|
| 그냥 누워있음 | 0 | 0 | 안 함 (0) |
| 친구랑 하이파이브 | 0 | 1 | 안 함 (0) |
| 친구가 뒤통수를 침 | 1 | 0 | **해야 함 (1)** |

### 1단계: 값을 단순히 더하기만 해보면?

- 입력값을 그냥 더함: `뒤통수 + 손바닥`
- `0+0=0`, `0+1=1`, `1+0=1` → 자극이 하나라도 있으면 무조건 1 (정색)
- 문제: 하이파이브(0,1)처럼 정색할 필요 없는 상황에서도 정색하게 됨 → **너무 민감함**

### 2단계: 바이어스(Bias)로 민감도 조절

> **바이어스 = 신경의 민감도를 조절해주는 값**

- 계산 방식: `(입력값들의 합) + 바이어스`
- 바이어스를 `-2`로 설정해서 둔감하게 만들어보면:
  - `(0,1)` 상황: `0 + 1 - 2 = -1` → 출력 0 (정색 안 함) ✅ 올바름

### 3단계: 그런데 뒤통수 맞은 상황도 확인해보니...

- `(1,0)` 상황(뒤통수 맞음): `1 + 0 - 2 = -1` → 출력 0 (정색 안 함) ❌ 틀림! 정색해야 하는데 안 함

→ 바이어스만으로는 부족함. **입력마다 중요도가 다르다**는 걸 반영해야 함

### 4단계: 웨이트(Weight)로 중요도 부여

> **웨이트 = 각 입력의 중요도를 반영해서 곱해주는 값**

- 뒤통수는 중요하니까 웨이트 `10`
- 손바닥은 상대적으로 덜 중요하니까 웨이트 `1`
- 계산 방식: `(입력 × 웨이트)의 합 + 바이어스`

**재계산**
- `(1,0)` 상황: `1×10 + 0×1 - 2 = 8` → 양수 → 출력 1 (정색함) ✅
- `(0,1)` 상황: `0×10 + 1×1 - 2 = -1` → 음수 → 출력 0 (정색 안 함) ✅
- `(0,0)` 상황: `0×10 + 0×1 - 2 = -2` → 음수 → 출력 0 (정색 안 함) ✅

→ 웨이트와 바이어스를 잘 조절하니 세 상황 모두 올바르게 대응하는 **"융통성 있는" 인공 신경 하나가 완성됨**

## 3. 인공 신경의 구성 요소 정리

| 용어 | 의미 |
|---|---|
| **노드 (Node)** | 동그라미로 표현되는 신경 자체 |
| **엣지 / 커넥션 (Edge / Connection)** | 노드를 연결하는 짝대기(선) |
| **웨이트 (Weight)** | 입력값에 곱해지는 값 = **중요도** |
| **바이어스 (Bias)** | 최종 값에 더해지는 값 = **민감도(역치)** 조절 |
| **액티베이션 (Activation, 활성화 함수)** | 전달할지 말지(활성화 여부)를 결정하는 함수 |

### 계산 순서: 곱하고 → 더하고 → 액티베이션
```
출력 = 활성화함수( (입력1 × 웨이트1) + (입력2 × 웨이트2) + ... + 바이어스 )
```

### 이번 예시에서 사용한 활성화 함수: Unit Step Function (유닛 스텝 함수)

- **Unit** = 1이라는 의미
- **Step** = 계단 모양 (그래프가 계단처럼 뚝 떨어짐)
- 규칙: 입력값(들 값)이 **0 이하(음수 포함)면 0**, **양수면 1** 출력

---

## 4. 웨이트와 바이어스를 정하는 것 = "학습"의 실체

- 지금까지는 사람이 직접 웨이트/바이어스 값을 정함 (쉬운 문제라 가능했음)
- 하지만 복잡한 문제에서는 사람이 일일이 정하기 어려움
- → **AI가 스스로 웨이트와 바이어스 값을 알아내는 것 = 학습(Learning)**

> 즉, "AI가 학습한다"는 표현의 실체는 **적절한 웨이트와 바이어스 값을 찾아내는 것**

---

## 5. 인공신경 → 인공신경망으로 확장

여러 인공 신경이 서로 연결되어 "망(Network)"을 이루면 → **인공신경망 (Artificial Neural Network)**

### 예시: 발바닥 자극 → 중간층 → 다음 층

- 입력: 왼쪽 발바닥, 오른쪽 발바닥, 또 다른 자극 (총 3군데)
- 중간에 있는 노드도 이제 **"전달받는 대상"**이자 **"전달하는 주체"** 역할을 함
  - 비유: 끝부분(입력) = 말초신경계, 중간 = 중추신경계
- 각 연결마다 동일하게 **웨이트 곱하기 → 바이어스 더하기 → 액티베이션**을 반복

### 왜 여러 개의 노드(신경)가 필요한가?

- 만약 여러 노드의 웨이트가 전부 똑같다면? → 모든 노드가 같은 값을 출력 → **의미 없음** (중복)
- **여러 개의 노드를 쓴다는 것은, 각 노드가 서로 다른 역할을 하길 기대하는 것**
  - 예: 어떤 노드는 "위쪽 자극"에 민감하게, 어떤 노드는 "아래쪽 자극"에 민감하게 웨이트를 다르게 설정
- 노드가 너무 많으면 → 중복되는(쓸모없는) 값을 계속 만들어냄 → **오버피팅**의 원인 중 하나
  - → 노드 개수도 적절해야 하고, 웨이트가 충분히 달라질 수 있는 구조가 중요함

## 6. 인공신경망의 구조 용어

### 웨이트 & 바이어스 개수 세는 법 (꿀팁)

> **연결(커넥션) 개수 × 이전 층 노드 수 × 다음 층 노드 수 + 다음 층 노드 수(바이어스 개수)**

- 예: 입력 2개 → 출력 1개
  - 웨이트: `2 × 1 = 2`, 바이어스: `1개`
  - 합계: `2×1 + 1`
- 예: 입력 3개 → 은닉 2개
  - 웨이트: `3 × 2 = 6`, 바이어스: `2개`
  - 합계: `3×2 + 2`

### 레이어(층) 구분

| 레이어 | 의미 |
|---|---|
| **인풋 레이어 (Input Layer)** | 맨 처음 입력값이 들어오는 층 |
| **히든 레이어 (Hidden Layer)** | 중간에 있는 층 (웨이트+바이어스+액티베이션 포함) — **1층 이상 존재해야 함** |
| **아웃풋 레이어 (Output Layer)** | 웨이트, 바이어스를 거쳐 최종 값이 나오는 층 |

> **왜 "멀티(Multi)"인가?**: 히든 레이어가 최소 1층은 있어야 "인풋 → 히든 → 아웃풋"으로 최소 3개 층 구조가 되기 때문에, 히든 레이어가 반드시 1층 이상 존재해야 함

### 완전 연결 구조 = Fully Connected (FC)

- 모든 노드가 다음 층의 모든 노드와 전부 연결된 구조를 **풀리 커넥티드(Fully Connected)**라고 부름
- 이런 구조로 이루어진 신경망을 **MLP (Multi-Layer Perceptron, 다층 퍼셉트론)**이라고 부름

> 참고: 옛날 퍼셉트론(Perceptron)은 유닛 스텝 함수(Unit Step Function)만을 활성화 함수로 사용했던 초기 형태의 인공 신경 모델

## 7. 이번 강의 핵심 요약

- [x] 인공 신경 = 실제 신경의 "전달받기 → 전달여부 결정 → 전달하기" 과정을 본뜬 것
- [x] **노드(Node)**와 **엣지/커넥션(Edge/Connection)**으로 구성
- [x] **웨이트(Weight)** = 중요도, **바이어스(Bias)** = 민감도

- [x] 인풋 레이어 / 히든 레이어(1층 이상) / 아웃풋 레이어 구조
- [x] Fully Connected 구조 = **MLP (Multi-Layer Perceptron)**

## 용어 정리

| 용어 | 의미 |
|---|---|
| 노드 (Node) | 인공 신경 하나 (동그라미) |
| 엣지 / 커넥션 (Edge / Connection) | 노드 간 연결 (짝대기) |
| 웨이트 (Weight) | 입력의 중요도를 나타내는 곱셈 계수 |
| 바이어스 (Bias) | 신경의 민감도(역치)를 조절하는 덧셈 값 |
| 액티베이션 (Activation) | 활성화 함수 — 전달 여부를 결정 |
| Unit Step Function | 계단 모양의 활성화 함수 (음수→0, 양수→1) |
| 인풋 레이어 (Input Layer) | 입력값이 들어오는 층 |
| 히든 레이어 (Hidden Layer) | 입력과 출력 사이의 중간 층 |
| 아웃풋 레이어 (Output Layer) | 최종 출력이 나오는 층 |
| Fully Connected (FC) | 모든 노드가 다음 층 모든 노드와 연결된 구조 |
| MLP (Multi-Layer Perceptron) | Fully Connected로 이루어진 다층 신경망 |
