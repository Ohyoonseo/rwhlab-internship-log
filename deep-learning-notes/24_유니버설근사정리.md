# 24강. 유니버설 근사정리 (Universal Approximation Theorem)

> 딥러닝 강의 24강 정리 노트

---

## 1. 핵심 질문: 인공신경망에 한계가 있을까?

> **놀라운 결론: 히든 레이어가 단 1층만 있어도, 어떠한 연속 함수든 다 표현할 수 있다**

- 이것을 **유니버설 근사정리 (Universal Approximation Theorem)**라고 부름
- 조건:
  - **히든 레이어**: 비선형(Non-linear) 활성화 함수 사용
  - **출력층**: Linear Activation 사용
  - **노드 개수**: 제한이 없어야 함 (충분히 많아야 함)

### 왜 이게 중요한가?

- "왜 굳이 인공신경망 형태(웨이트 곱하고, 액티베이션 통과 반복)를 써야 하나? 2차함수, 3차함수, 코사인, 사인 같은 다른 함수를 쓰면 안 되나?"라는 의문에 대한 답
- **정답: 그런 함수들도 전부 인공신경망으로 표현 가능함** — `x²`, `x³`, `cos(x)` 등 무엇이든 인공신경망 구조 안에서 재현할 수 있음
- 그래서 굳이 다른 함수 형태를 고민할 필요 없이, **그냥 인공신경망(웨이트·바이어스·액티베이션의 반복)을 쓰면 됨**

### ChatGPT도 결국 "함수"

- 입력 채팅을 넣으면 출력 채팅이 나오는 것도 결국 함수
- 처음 보는 채팅에도 적절히 대응하는 이유 = 학습을 통해 **적절한 함수를 찾았기 때문**

## 2. 증명: "깍두기(스텝 함수)"를 조합해서 어떤 데이터든 완벽히 통과시키기

> 미국의 한 블로거가 제시한 직관적인 증명 방식 (엄밀한 수학적 증명은 아니지만 이해하기 쉬움)

### 예시 데이터: 조회수-수익

```
조회수 1,000 → 수익 1,000원
조회수 2,000 → 수익 3,000원
조회수 3,000 → 수익 2,000원
```

### 첫 번째 데이터 하나를 완벽히 맞추는 함수 만들기

**구조**: 히든 레이어의 두 노드에 **Unit Step Function** 사용

```
노드 1: 웨이트=1, 바이어스=-900   → 조회수가 900을 넘으면 1로 뜀 (900에서 계단처럼 올라감)
노드 2: 웨이트=1, 바이어스=-1100  → 조회수가 1100을 넘으면 1로 뜀 (1100에서 계단처럼 올라감)
```

**출력층(Linear Activation)에서 결합**

```
노드 1의 출력에 웨이트 +1,000원을 곱함
노드 2의 출력에 웨이트 -1,000원을 곱함
두 값을 더함
```

- 900 지점: 노드1만 켜짐(1) → `+1,000원`
- 1100 지점: 노드1도 켜지고 노드2도 켜짐 → `+1,000 - 1,000 = 0원`
- 결과: **900에서 1,000원으로 확 뛰었다가, 1100에서 다시 0원으로 뚝 떨어지는 "깍두기(사각형 펄스)" 모양**의 함수가 만들어짐

> **이 깍두기를 조회수 1,000 지점에 정확히 씌우면, 그 지점에서만 1,000원이 출력되도록 만들 수 있음 → 첫 번째 데이터에 대한 트레인 로스를 정확히 0으로 만드는 함수 완성**

### 데이터가 늘어나면? — 데이터 하나당 노드 2개씩 추가

**두 번째 데이터(조회수 2,000 → 수익 3,000원)를 위한 깍두기**

```
노드 3: 웨이트=1, 바이어스=-1900
노드 4: 웨이트=1, 바이어스=-2100
출력층 웨이트: 각각 +2,000원, -2,000원
```

**세 번째 데이터(조회수 3,000 → 수익 2,000원)를 위한 깍두기**

```
노드 5: 웨이트=1, 바이어스=-2900
노드 6: 웨이트=1, 바이어스=-3100
출력층 웨이트: 각각 +2,000원, -2,000원
```

- 각 깍두기는 서로 다른 조회수 구간에서만 반응하므로 **서로 간섭하지 않음**
- 이 깍두기들을 전부 더해주면(출력층에서 자연스럽게 더해짐), **세 개의 데이터를 모두 정확히 통과하는 하나의 함수**가 완성됨

### 일반화: 데이터가 아무리 많아도, 노드만 충분하면 된다

> **데이터 하나당 노드 2개씩 계속 추가하면서, 빈틈없이 깍두기를 촘촘하게 세워나가면, 결국 어떤 모양의 곡선(코사인 x 같은 복잡한 함수 포함)도 만들어낼 수 있다**

- 히든 레이어는 **단 1층**이면 충분 — 다만 노드 개수는 매우 많아야 함
- 이것이 바로 유니버설 근사정리의 증명 아이디어

## 3. 중요한 주의사항: 이건 "학습 원리"가 아니라 "표현 가능성"에 대한 증명

> **실제로 신경망이 학습될 때 이런 식으로(깍두기를 하나씩 쌓는 방식으로) 웨이트가 정해지는 것은 아님!**

- 이 증명은 "이런 식으로 웨이트/바이어스를 손수 잡아볼 수 있다"는 것을 보여줌으로써, **"히든 레이어 1개만으로도 어떤 함수든 표현할 수 있는 잠재력이 있다"**는 사실을 반박 불가능하게 입증하는 것
- 실제 학습은 여전히 그라디언트 디센트를 통해 이루어짐

### 참고: 이런 방식으로 실제 데이터를 완벽히 맞추면 오히려 문제

- 위 증명처럼 트레인 데이터 각각을 정확히 맞추는 깍두기 함수를 만들면, 이것은 사실 **극단적인 오버피팅**에 해당함
- "표현할 수 있다"는 것과 "그렇게 학습시키는 게 좋다"는 것은 별개의 문제

---

## 4. 그렇다면 왜 굳이 깊은(Deep) 신경망을 쓰는가?

> **히든 레이어 1개로도 이론상 가능하지만, 매우 비효율적이기 때문**

- 위 증명에서 봤듯, 데이터(또는 표현하려는 함수의 복잡도)가 늘어날수록 필요한 노드 수가 기하급수적으로 늘어남 (데이터 하나당 노드 2개씩!)
- 노드를 몇억 개씩 쓸 수는 없으므로, **층을 깊게(Deep) 만들면 훨씬 적은 노드 수로도 복잡한 함수를 효율적으로 표현할 수 있음**

> **정리: 유니버설 근사정리는 "1층으로도 이론상 가능하다"를 보여주지만, "실용적으로 효율적이다"는 것은 아니다. 그래서 딥러닝에서는 층을 깊게 쌓는다.**

---

## 5. 참고 (심화): Fully Connected가 아닌 레이어도 쓸 수 있다

- 예: 입력 `(a,b,c,d)` 4개 값이 들어와서, `ac+bd` (벡터 `(a,b)`와 `(c,d)`의 내적) 형태의 출력을 원한다고 가정
- 이걸 일반적인 Fully Connected 인공신경망 구조로 표현하려면 (유니버설 근사정리에 의해 가능은 하지만) 비효율적
- **그냥 "내적을 계산하는 레이어"를 직접 만들어서 신경망 사이에 끼워 넣어도 됨**
- 조건은 단 하나: **미분 가능해야 함** (백프로파게이션을 위해 출력부터 입력까지 전부 미분 가능해야 하므로)
- 참고로 내적 연산은 **트랜스포머(Transformer)**에서 "유사도(닮은 정도)"를 계산하는 중요한 연산으로 실제로 많이 사용됨

## 6. 다른 활성화 함수, 다른 입력 차원에서도 성립

- 이번 증명은 Unit Step Function으로 설명했지만, **시그모이드, ReLU 등 다른 활성화 함수를 사용해도 비슷한 방식으로 증명 가능** (강사의 이전 강의에서 다룸)
- 입력 노드가 1개가 아니라 **여러 개(2개, 3개...)인 경우에도 동일한 원리로 증명 가능**
  - 입력이 2개면 2차원 깍두기가 아니라 **3차원 깍두기**를 쌓는 방식으로 확장
  - 입력이 3개, 4개... 로 늘어나도 같은 방식으로 확장 가능

## 7. 정리: 인공신경망은 왜 강력한가?

> **인공신경망(인공 신경 하나하나)은 그저 "곱하고, 더하고, 액티베이션 통과"하는 아주 단순한 연산일 뿐이다**

- 하지만 이런 **단순한 연산 단위(인공 신경)들이 아주 많이 모여서** 힘을 합치면, 이론상 **어떤 복잡한 함수도 표현할 수 있는 강력한 존재**가 됨
- **AI가 "학습한다"는 것의 실체** = 원하는 출력이 나오도록 그라디언트를 이용해 웨이트 값들을 계속 업데이트해나가는 것 — 그게 전부

---

## 8. 다음 예고: 그렇다면 그냥 깊고 노드 많은 신경망을 만들면 만사형통?

> **아니다! 여러 문제가 발생한다**

- **베니싱 그라디언트(Vanishing Gradient)**: 레이어가 많아질수록, 입력층에 가까운 층일수록 그라디언트(미분값)가 점점 작아져서 거의 사라지는 문제
- **오버피팅(Overfitting)**: 노드/레이어가 너무 많으면 학습 데이터에 과도하게 맞춰짐
- **로스 랜드스케이프가 꼬불꼬불해짐**: 층이 깊어질수록 로스 함수의 형태가 더 복잡(논컨벡스)해지는 문제

> 다음 강의에서 **베니싱 그라디언트** 문제부터 자세히 다룰 예정 — 백프로파게이션 수식에서 그 힌트를 이미 얻을 수 있었음

## 9. 이번 강의 핵심 요약

- [x] **유니버설 근사정리**: 히든 레이어가 단 1층만 있어도(노드 수만 충분하다면), 어떠한 연속 함수든 인공신경망으로 표현 가능
- [x] 굳이 2차함수, 코사인 등 다른 형태의 함수를 고민할 필요 없이, **인공신경망 구조 자체가 이미 만능**임
- [x] 증명 아이디어: 데이터(또는 표현하려는 지점) 하나당 **Unit Step Function 노드 2개**를 사용해 "깍두기(사각 펄스)" 모양을 만들고, 이를 여러 개 겹쳐 쌓아서 원하는 함수 모양을 완성
- [x] 이 증명은 "표현 가능성"을 보여주는 것이지, **실제 학습(그라디언트 디센트) 방식과는 무관함**
- [x] 히든 레이어 1개로도 가능하지만 **노드 수가 기하급수적으로 필요해 비효율적** → 그래서 **깊은(Deep) 신경망**을 사용하는 것이 실용적
- [x] 미분 가능하기만 하면, Fully Connected가 아닌 다른 형태의 레이어(예: 내적 계산 레이어)도 신경망 안에 자유롭게 사용 가능
- [x] 다른 활성화 함수, 다차원 입력에서도 같은 원리로 증명 확장 가능
- [x] 다음 강의 예고: 깊고 큰 신경망을 만들 때 생기는 문제들 — **베니싱 그라디언트, 오버피팅, 복잡한 로스 랜드스케이프**

---

## 용어 정리

| 용어 | 의미 |
|---|---|
| 유니버설 근사정리 (Universal Approximation Theorem) | 히든 레이어 1층(노드 수 충분)만 있어도 어떤 연속 함수든 인공신경망으로 표현 가능하다는 정리 |
| 깍두기 (Step Pulse) | 두 개의 Unit Step Function 노드를 조합해서 만든 사각형 모양의 함수 |
| 베니싱 그라디언트 (Vanishing Gradient) | 레이어가 깊어질수록 입력층에 가까운 곳의 그라디언트가 점점 작아져 사라지는 문제 (다음 강의 예고) |
