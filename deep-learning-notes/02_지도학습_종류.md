# 2강. 머신러닝의 분류와 지도학습의 다양한 예시

> 딥러닝 강의 2강 정리 노트

---

## 1. 머신러닝의 4가지 분류

머신러닝은 크게 4가지로 나눌 수 있음:

- **지도학습** (Supervised Learning)
- **비지도학습** (Unsupervised Learning)
- **자기지도학습** (Self-supervised Learning)
- **강화학습** (Reinforcement Learning)

### 딥러닝 사용 여부는 별개의 축

이 4가지 분류 안에서도 **딥러닝(DNN)을 사용하는지 아닌지**는 또 다른 기준임.

- 지도학습 영역 안에도:
  - 딥러닝(DNN) 기반 → 예: CNN
  - 딥러닝 아닌 것 → 예: SVM
- 강화학습도 마찬가지로 딥러닝 기반 / 비딥러닝 기반이 따로 존재함

> 즉, "학습 방식(지도/비지도/자기지도/강화)"과 "딥러닝 사용 여부"는 서로 별개의 기준이라 겹쳐서 나뉨

이번 강의에서는 **지도학습만** 집중적으로 다룸.

---

## 2. 지도학습이란?

**정답(라벨)을 알고 있는 상태로 학습하는 것**

- "이 사진은 강아지야", "이 사진은 1이야" 처럼 **정답을 미리 사람이 만들어 놓아야 함**
- 이 작업을 **레이블링(Labeling)** 이라고 부름
- 문제점: 사람이 직접 정답을 다 달아야 하므로 **노가다(비용이 많이 듦)**

### 지도학습의 두 갈래: 분류 vs 회귀

| 구분 | 정의 | 예시 |
|---|---|---|
| **분류 (Classification)** | 출력이 **딱딱 떨어지는 값** (카테고리) | 강아지 / 고양이 구별 |
| **회귀 (Regression)** | 출력이 **연속된 값** | 위치 좌표, 크기 등 숫자 값 |

> 핵심 기준: 최종 출력이 "딱 떨어지는 카테고리"면 분류, "연속된 숫자"면 회귀

---

## 3. 지도학습의 다양한 문제 유형

### (1) Classification (분류)
- 입력: 사진
- 출력: 강아지 / 고양이 여부 (0 또는 1)
- 이전 강의에서 다룬 기본적인 CNN 예시

### (2) Localization (분류 + 회귀)

**"이 사진은 고양이이며, 고양이는 여기 있다"** 를 동시에 예측

- 필요한 정보: **4개의 숫자**
  - `x, y` : 박스의 위치 (좌표)
  - `w, h` : 박스의 너비(Width), 높이(Height)
- 즉, **분류(고양이인지 아닌지) + 회귀(박스 좌표/크기)** 가 결합된 문제

**학습 방식**
- CNN 모델에 사진을 입력
- 이전에는 출력이 `0` 또는 `1` 하나였다면, 이번엔 `x, y, w, h` 4개의 숫자가 출력되도록 학습
- 정답 데이터: 사람이 사진을 보고 직접 박스를 쳐서 `x, y, w, h` 값을 미리 만들어 놓음
- 수천~수만 장의 (사진, 박스좌표) 쌍으로 학습시키면, 처음 보는 사진에서도 위치를 예측 가능

### (3) Object Detection (객체 탐지)

- Localization과 원리는 동일하지만, **여러 개의 객체**를 동시에 탐지
- 출력: `(객체1: 분류 + x,y,w,h)`, `(객체2: 분류 + x,y,w,h)` ... 이렇게 여러 묶음이 튀어나옴
- 인공신경망의 출력 뉴런 개수를 늘려서 여러 묶음을 동시에 출력하도록 구성

### (4) Instance Segmentation (인스턴스 분할)

- 원리는 오히려 더 단순: **픽셀 하나하나마다 분류**를 수행
- 예: 이 픽셀은 배경(background), 이 픽셀은 강아지, 이 픽셀은 고양이1, 이 픽셀은 고양이2...
- **인스턴스 분할**은 같은 종류(고양이)여도 개체별로 구분(고양이1, 고양이2)까지 해줌

**숫자 약속(라벨링) 예시**
```
배경(background) = 0
강아지 = 1
고양이 = 2
오리 = 3
```
- 이 숫자는 그냥 처음에 정하기 나름인 **약속**일 뿐임

**학습 방식**
- 입력: 이미지
- 출력: 각 픽셀마다 분류 값이 채워진 이미지(행렬)
- (엄밀히는 각 픽셀마다 정수 하나가 아니라 벡터가 나오는 구조지만, 개념만 이해하면 충분)

### (5) Pose Estimation (자세 추정)

- 사진을 넣으면 사람 신체의 주요 지점(머리, 목, 어깨, 배, 무릎, 발목 등)의 좌표를 예측
- CNN을 이용해서 각 관절 포인트의 `(x, y)` 좌표들이 벡터로 출력되도록 학습
- 예측된 좌표를 점으로 찍고, 점들을 규칙 기반(룰 베이스)으로 연결 (예: 머리-목 연결)
- **응용 예시**: 카메라 앞에서 동작하면 게임 캐릭터가 그대로 따라 움직이는 모션 캡처

**학습 방식**
- 정답: 사진 속 각 관절의 `(x, y)` 좌표를 미리 사람이 표시
- 이런 (사진, 좌표) 쌍을 대량으로 반복 학습

### (6) Face Landmark (얼굴 랜드마크)

- 스노우(Snow) 같은 얼굴 보정 앱의 원리
- 턱, 눈썹, 눈 등에 여러 개의 포인트(랜드마크)를 찍음
- 찍힌 포인트의 윤곽에 맞춰서 이미지를 보정
- 이것도 결국 지도학습: 사람이 미리 정답 포인트를 찍어놓은 데이터로 학습

---

## 4. 지도학습의 한계와 다음 이야기

- 지도학습의 공통점: **누군가 정답(라벨)을 만들어 놔야 한다**
- 문제가 어려울수록 → 정답 데이터를 만들기 어려움 → **데이터가 부족해짐**
- 정답이 있는 데이터를 구하는 데 **비용이 많이 듦**
- → 이런 한계 때문에 **자기지도학습(Self-supervised Learning)** 같은 방법이 등장

### 비지도학습 (참고, 이번 수업 범위 아님)
- **정답을 모르는 상태**로 학습
- 예: 군집화(Clustering), 차원 축소 (PCA, SVD 등)
- 이 강의(수업)에서는 **지도학습만** 다룰 예정

## 5. 이번 강의 핵심 요약

- [x] 머신러닝은 지도/비지도/자기지도/강화학습 4가지로 분류되며, **딥러닝 사용 여부는 별개의 축**
- [x] 지도학습 = 정답(라벨)을 알고 학습 / 비지도학습 = 정답을 모르고 학습
- [x] **분류(Classification)**: 출력이 딱 떨어지는 카테고리
- [x] **회귀(Regression)**: 출력이 연속된 값
- [x] Localization = 분류 + 회귀 (`x, y, w, h`)
- [x] Object Detection = Localization을 여러 객체로 확장
- [x] Instance Segmentation = 픽셀 단위 분류 + 개체 구분
- [x] Pose Estimation = 관절 좌표 예측
- [x] Face Landmark = 얼굴 특징점 예측 (얼굴 보정 앱 원리)
- [x] 지도학습의 한계: 라벨링 비용이 크다 → 자기지도학습 등장 배경
