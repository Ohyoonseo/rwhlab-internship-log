# 1강. AI, 머신러닝, 딥러닝의 개념

> 딥러닝 강의 1강 정리 노트

---

## 1. AI란 무엇인가?

**AI = 인간의 지능을 인공적으로 만든 것**

- 지능 = 지적 능력 (예: 강아지 vs 고양이 구별)
- 핵심 질문은 **"How"** — *어떻게* 구별했는가?
- → 인간의 사고 방식을 **수학적으로 모델링**해서 풀어낸 것이 바로 **딥러닝의 핵심**

### AI ⊃ 머신러닝 ⊃ 딥러닝

```
AI
 └─ 머신러닝 (Machine Learning)
     └─ 딥러닝 (Deep Learning)
```

| 구분 | 정의 |
|---|---|
| AI | 지능을 인공적으로 구현한 것 (가장 큰 범위) |
| 머신러닝 | AI 중에서 **데이터를 기반으로** 학습하는 방식 |
| 딥러닝 | 머신러닝 중에서 **DNN(Deep Neural Network, 깊은 인공신경망)**을 사용해 학습하는 방식 |

---

## 2. 규칙 기반 알고리즘 vs 머신러닝

같은 문제(강아지/고양이 분류)를 푸는 두 가지 다른 접근법 비교.

### 규칙 기반 알고리즘 (기존 방식)
- **사람이** 직접 규칙을 만듦
  - "귀가 둥그스름하면 고양이", "코가 삐죽하면 강아지" 등
- 규칙을 `if-else` 조건문으로 하드코딩
- 문제점: 좋은 규칙을 알아내는 것 자체가 어려움

### 머신러닝 방식
- **사람이 규칙을 몰라도 됨** — 정답(라벨)만 알려주면 AI가 스스로 규칙을 깨달음
- **훈련(Training) 과정**
  - "이 사진은 강아지야", "이 사진은 고양이야" 라고 대량으로 알려줌
  - 다양한 케이스를 학습시켜야 함:
    - 정면 사진, 뒤집힌 사진
    - 서 있는 자세, 누워 있는 자세
    - 일부만 보이는 사진 (예: 엉덩이만 보이는 사진)
  - → 여러 변형된 예시를 충분히 보여줘야 새로운 상황에도 잘 인식함
- **테스트(Test) 과정**
  - 핵심: **한 번도 본 적 없는** 새로운 사진으로 검증
  - 처음 보는 강아지 사진 → 강아지라고 잘 맞히는지 확인
  - 처음 보는 고양이 사진 → 고양이라고 잘 맞히는지 확인

> **정리**: 규칙 기반 = 사람이 깨달아서 알려줌 / 머신러닝 = AI가 스스로 깨달음 (사람은 정답만 제공)

---

## 3. 딥러닝: 인공신경망(Neural Network) 사용

- **뉴럴 네트워크(Neural Network)**: 입력 → 여러 층으로 연결된 노드(동그라미)들 → 출력
- **딥러닝** = **깊은(층이 많은)** 인공신경망을 사용해서 학습하는 것

### 표기 규칙
- 뉴럴 네트워크 모델은 앞으로 **네모 박스**로 표현
- 예: CNN 모델, RNN 모델 → 각각 하나의 네모로 표시

---

## 4. CNN (Convolutional Neural Network) — 이미지에 강한 모델

### 핵심 원리: 입력과 출력은 모두 숫자!

> **중요 포인트**: 뉴럴 네트워크는 입력과 출력이 **전부 숫자**로 이루어져야 한다.

- 강아지 사진 입력 → 출력 **1**
- 고양이 사진 입력 → 출력 **0**
- 이렇게 숫자로 미리 대응(라벨링)을 약속해두고, 무한 반복 학습시킴

### 이미지도 사실 숫자다 (행렬)

- 이미지 = 픽셀 값들의 **행렬(Matrix)**
  - 가로 줄 = 행(row), 세로 줄 = 열(column)
  - 픽셀 값이 작으면 어두움, 크면 밝음
- **컬러 사진 = 3차원 행렬**
  - R(빨강), G(초록), B(파랑) 3개 채널
  - 각 채널마다 위치별로 색상 강도 값이 있음
  - 세 색을 섞어서 하나의 색으로 인식 (모니터의 LED도 RGB가 촘촘히 배치된 구조)

### 행렬 크기 표기법

`3 × 5 × 5` 라고 쓰면:

- **행렬 순서 약속**: `채널 × 행 × 열`
- 앞의 **3** → RGB 3개 채널 (컬러 이미지)
- **5 × 5** → 이미지 사이즈 (5행 5열)
- 읽는 법: "3바 5바 5" (숫자 사이는 `×`가 아니라 "바"로 읽음)

> 앞으로 이 강의에서는 항상 **채널 × 행 × 열** 순서로 행렬 크기를 표기함

## 5. RNN (Recurrent Neural Network) — 연속적인 데이터에 강한 모델

- CNN이 이미지에 강하다면, **RNN은 연속적인 데이터(예: 문장)**에 강함
- 예시: 번역 모델
  - 입력: "저는 강사입니다" (한글 문장)
  - 출력: "I am an instructor" (영어 문장)

### 문장도 결국 숫자로 바꿔야 한다

1. **토크나이징(Tokenizing)**: 문장을 단위(토큰)로 쪼갬
   - 예: "저는 강사입니다" → 이 문장을 특정 기준으로 분리 (띄어쓰기 등 다양한 규칙 존재)
2. 각 토큰을 **숫자(벡터)**로 변환
3. 숫자로 변환된 입력을 넣고, 대응되는 숫자(출력)가 나오도록 학습

> 실제로는 표현 가능한 단어 수가 매우 많기 때문에 벡터 길이가 굉장히 길어짐 (수만 개 단위)

## 용어 정리

| 용어 | 의미 |
|---|---|
| DNN | Deep Neural Network, 깊은 인공신경망 |
| CNN | Convolutional Neural Network, 이미지 처리에 강한 신경망 |
| RNN | Recurrent Neural Network, 연속 데이터 처리에 강한 신경망 |
| 토크나이징 | 문장을 의미 단위(토큰)로 쪼개는 작업 |
| 채널 | 이미지의 색상 정보 층 (RGB = 3채널) |
