# 4강. 강화학습 (Reinforcement Learning)

> 딥러닝 강의 4강 정리 노트

---

## 1. 강화학습이란?

> **내가 원하는 행동을 하게끔 "강화"시킨다** 해서 강화학습

- 비유: 강아지 손 훈련
  - 강아지가 "손" 행동을 했을 때만 간식(보상)을 줌
  - → 그 특정 행동이 점점 더 자주 나오도록 **강화**됨
- AI도 동일한 원리
  - 예: 알파고 — 바둑에서 **이겼을 때만 리워드**를 줌
  - 이런 방식만으로 AI가 스스로 "어떻게 둬야 이길 수 있는지"를 알아냄

---

## 2. 강화학습의 핵심 용어

| 용어 | 의미 | 강아지 훈련 예시 | 오목/바둑 예시 |
|---|---|---|---|
| **에이전트 (Agent)** | 행동의 주체 | 강아지 | 흑돌(AI) |
| **액션 (Action)** | 에이전트가 할 수 있는 행동 | 손, 앉아, 뒤로 돌아 등 | 어디에 돌을 두는지 (수) |
| **리워드 (Reward)** | 특정 행동에 대한 보상 | 간식 | 승점 (이기는 것) |
| **인바이런먼트 (Environment)** | 리워드를 언제/얼마나 줄지 설계된 환경 | 주인 | 심판 + 백돌(상대) |

### 예시로 이해하기: 오목
- 검은색 돌 = AI(에이전트), 흰색 돌 = 사람
- 검은색이 이기는 수(예: 4개를 완성)를 뒀을 때만 리워드를 줌
- 처음엔 랜덤하게 두다가, 충분히 학습되면 이기는 패턴을 스스로 알아냄

---

## 3. 예시: "1주년 맛집 찾기" (강화학습은 적기다, 강은 맞이다)

강화학습을 길찾기(미로) 문제로 비유

### 상황 설정 (Environment)
- 판을 격자(그리드)로 나눔
- 특정 칸에 도달하면 리워드/페널티가 있음
  - 예: "시유(CU)"로 가면 **-100점** (뺨 맞고 헤어짐)
  - "KB(김밥천국 같은 한식집)"로 가면 **-10점**
  - 목표 지점(진짜 맛집)에 도달하면 **+100점**
- 선택지: 상/하/좌/우로 이동 가능

### 핵심 개념: State와 Q-function

| 용어 | 의미 |
|---|---|
| **스테이트 (State)** | 현재 위치(좌표) — "지금 어디 있는가" |
| **Q 펑션 (Q-function)** | 특정 state에서 특정 action을 했을 때 기대할 수 있는 리워드 점수 |
| **에피소드 (Episode)** | 한 번의 전체 시도 (예: "몇 번째 여친이냐") |

> **Q function = State(위치)와 Action(행동)에 대한 함수**
> → "이 위치에서 이 행동을 했을 때 몇 점짜리 행동이냐"를 알려주는 함수

### 학습 과정 (에피소드를 반복하며 경험 쌓기)

- **에피소드 1 (첫 번째 시도)**
  - Q 함수 값이 전부 0 (아무 경험 없음)
  - → 랜덤(예: 1/4 확률)으로 아무 방향이나 선택
  - 우연히 나쁜 곳(-100점)으로 이동 → 에피소드 종료

- **에피소드 2**
  - 이전 경험(Q 값)으로 "그 방향은 나쁘다"는 걸 이미 앎
  - 나머지 선택지 중에서 다시 랜덤(1/3 확률)으로 선택
  - 또 안 좋은 결과가 나올 수 있지만, 조금씩 나아짐

- **에피소드를 반복할수록**
  - 점점 더 많은 칸의 Q 값이 채워짐
  - 결국 목표 지점(+100점)까지 가는 좋은 경로를 학습하게 됨

> Q 함수 값 = 경험치가 쌓여가는 것

---

## 4. Q-러닝 (Q-Learning): Q 값을 업데이트하는 방법

### 핵심 규칙
> **이동하고 난 후, 새로 도착한 위치에서 가능한 행동들의 Q값 중 가장 큰 값을 가져와서, 이전 위치·행동의 Q값을 업데이트한다**

### 예시
1. 현재 위치에서 랜덤(1/4 확률)으로 오른쪽을 선택해 이동
2. 이동한 곳에서 보니, 그 다음 칸으로 가는 선택지 중 가장 큰 Q값이 100임을 확인
3. → 방금 전 위치에서 "오른쪽으로 간 행동"의 Q값을 **100**으로 업데이트

- 이 과정을 수많은 에피소드에 걸쳐 반복하면, 결국 전체 경로의 Q값 테이블이 완성됨
- **딥러닝(DNN)을 이용해서 Q값을 추정하면** → **Deep Reinforcement Learning (딥 강화학습)**
  - 강화학습 자체는 기존 머신러닝의 한 갈래였지만, 여기에 딥러닝을 적용한 것

## 5. 익스플로레이션 (Exploration, 탐험)

### 문제 상황
- Q-러닝만으로 학습하면 "그럭저럭 괜찮은 길"을 찾은 순간, 계속 그 길만 반복하게 됨
- 하지만 근처에 훨씬 더 좋은 길(예: 숨겨진 골목의 미슐랭 맛집, 리워드 +1000)이 있어도 **발견하지 못함**
- → 매너리즘/과최적화 문제

### 해결책: ε-greedy (입실론 그리디)

- **ε(입실론)** 값을 0~1 사이로 설정 (예: `ε = 0.1`)
- **ε의 확률만큼 Q값을 무시하고 완전히 랜덤한 행동을 선택** (일탈)
  - 예: ε = 0.1이면, 매 행동마다 10% 확률로 랜덤하게(탐험) 움직임
- 나머지 확률(90%)은 기존처럼 Q값이 가장 좋은 행동을 선택

### 효과
- 에피소드를 수천~수만 번 반복하는 동안, 가끔씩의 "일탈"로 인해 새로운 경로를 발견
- 새로운 경로가 더 좋다는 것을 알게 되면 Q값이 갱신되고, 결국 최적의 길을 찾아냄

### 바둑/게임에서의 의미
- 사람은 보통 익숙한 패턴대로만 수를 둠
- AI는 익스플로레이션을 통해 **사람이 두지 않던 새로운 수**를 스스로 개발
- 알파고가 인간의 정석을 뛰어넘은 것도 바로 이 원리
  - 이세돌의 표현: "이건 사람의 바둑이 아니라 신의 바둑이다"

## 6. 디스카운트 팩터 (Discount Factor)

### 문제 상황
- 같은 점수(+100)를 주는 두 목표 지점이 있는데, 하나는 가깝고 하나는 멀리 돌아가야 하는 상황
- 지금까지 배운 개념(Q-러닝 + 익스플로레이션)만으로는 **어느 쪽이 더 효율적인지 구분하지 못함**
  - 둘 다 최종 Q값이 100으로 같아 보이기 때문

### 해결책
- **디스카운트 팩터(할인율, 보통 γ 감마로 표기)**: 0~1 사이 값 (예: `γ = 0.9`)
- Q값을 이전 위치로 가져올 때, **한 칸 이동할 때마다 감마를 곱해서 점점 깎아서(할인해서) 가져옴**

### 예시 계산
```
목표 지점 리워드: 100
한 칸 앞: 100 × 0.9 = 90
두 칸 앞: 90 × 0.9 = 81
세 칸 앞: 81 × 0.9 ≈ 73
...
```
- 즉, **목표까지 멀리 돌아갈수록 값이 더 많이 깎임**
- 이를 통해 "가까운 목표"와 "먼 목표" 중 **더 가까운 쪽의 Q값이 더 높게** 계산되어, 효율적인 경로를 구분할 수 있게 됨

> **디스카운트 = 세일(할인)**: 리워드를 받기까지 멀수록(스텝이 많을수록) 그 가치를 깎아서 반영한다는 의미

## 7. 이번 강의 핵심 요약

- [x] 강화학습 = 원하는 행동을 리워드로 **강화**시키는 학습 방식
- [x] 핵심 용어: **에이전트, 액션, 리워드, 환경(Environment)**
- [x] **State(상태)**와 **Q-function**: 특정 상태에서 특정 행동의 기대 점수
- [x] **에피소드**를 반복하며 경험을 쌓아 Q값을 채워나감
- [x] **Q-러닝**: 이동 후 도착 지점의 최댓값을 가져와 이전 상태·행동의 Q값을 업데이트
- [x] **딥 강화학습**: Q값 추정에 딥러닝(DNN)을 사용하는 경우
- [x] **익스플로레이션(ε-greedy)**: 일정 확률로 무작위 행동을 하여 더 좋은 경로를 탐색
- [x] **디스카운트 팩터**: 목표까지 거리가 멀수록 리워드 가치를 할인하여, 더 효율적인 경로를 구분 가능하게 함

---

## 용어 정리

| 용어 | 의미 |
|---|---|
| 에이전트 (Agent) | 행동을 하는 주체 |
| 액션 (Action) | 에이전트가 취할 수 있는 행동 |
| 리워드 (Reward) | 특정 행동에 대해 주어지는 보상(점수) |
| 인바이런먼트 (Environment) | 리워드 부여 규칙이 설계된 환경 |
| 스테이트 (State) | 현재 상태 (예: 위치) |
| Q 펑션 (Q-function) | State와 Action에 대한 기대 보상 함수 |
| 에피소드 (Episode) | 한 번의 전체 시행(trial) |
| Q-러닝 (Q-Learning) | 다음 상태의 최댓값을 이용해 Q값을 업데이트하는 학습 방법 |
| 딥 강화학습 (Deep RL) | Q값 추정에 딥러닝(DNN)을 사용하는 강화학습 |
| 익스플로레이션 (Exploration) | 새로운 경로를 찾기 위한 무작위 탐험 |
| ε-greedy (입실론 그리디) | 일정 확률(ε)로 무작위 행동을 선택하는 탐험 전략 |
| 디스카운트 팩터 (Discount Factor, γ) | 목표까지의 거리에 따라 리워드를 할인하는 비율 |
