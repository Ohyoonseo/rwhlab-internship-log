# 30강. 정규화(Regularization)와 MAP 관점, 오버피팅 방지법 총정리

> 딥러닝 강의 30강 정리 노트 (시리즈 마지막 강의)

---

## 1. 레귤러라이제이션(Regularization)이란?

> **핵심 아이디어: 로스에 "웨이트의 크기"를 추가로 더해서, 웨이트 자체를 작게 유지하려는 압력을 준다**

```
새로운 로스 = 기존 로스 + 웨이트의 크기
```

### 벡터의 "크기(놈, Norm)" 복습

- 웨이트들을 벡터로 보면(`w1, w2, w3...`), 그 벡터의 "크기"를 나타내는 여러 방법이 있음
- **L1 놈(원 놈)**: 각 요소의 **절댓값**을 더한 것
- **L2 놈(투 놈)**: 각 요소의 **제곱을 더하고 루트**를 취한 것 (우리가 흔히 아는 "벡터의 크기")
  - 실제 레귤러라이제이션에서는 **제곱**(루트 씌우기 전 상태)을 사용

### 수식

```
로스_total = 로스 + λ × ||W||_p

p=1 이면 → L1 레귤러라이제이션
p=2 이면 → L2 레귤러라이제이션
```

- `λ(람다)`: 새로 추가되는 **하이퍼파라미터** — 웨이트 크기를 얼마나 중요하게 고려할지 조절

### λ의 극단적인 경우로 이해하기

| λ 값 | 의미 |
|---|---|
| `λ = 0` | 웨이트 크기를 전혀 신경 쓰지 않음 → 기존 로스만 고려하는 것과 동일 |
| `λ`가 매우 큼 (예: 1억) | 로스보다 웨이트 크기 줄이는 게 훨씬 이득 → **무조건 웨이트를 0으로 만들려고 함** (원래 문제를 아예 무시하게 됨) |

> **λ를 적절히 잘 잡아야, 로스도 잘 줄이면서 웨이트 크기도 함께 고려하게 됨**

## 2. 왜 웨이트를 줄이려고 하는가?

### 이유 ①: 로스에 별 영향 없는 웨이트는 없애서 모델을 경량화

- 어떤 웨이트를 계속 줄여봤는데(거의 0으로), **로스가 별로 변하지 않는다면** → 그 웨이트는 "있으나 마나 한" 웨이트였다는 뜻
- 이런 웨이트는 아예 없애버려서 **모델을 더 단순하게(경량화)** 만드는 것이 좋음

### 이유 ②: 웨이트 크기 자체가 "모델의 복잡도"와 관련 있다

> **웨이트 값이 크면 클수록, 함수의 그래프가 더 "꼬불꼬불(복잡)"해진다**

- 예: 다항함수에서 계수(웨이트에 해당)가 크면 클수록, 곡선이 더 극단적으로 휘고 요동침 (차수가 같아도 계수 크기에 따라 복잡도가 달라짐)
- 인공신경망의 웨이트도 마찬가지 원리 — **웨이트가 크면 클수록 표현하는 함수가 더 복잡(꼬불꼬불)해짐**
- 오버피팅된 모델은 트레이닝 데이터에 억지로 맞추기 위해 곡선을 과도하게 구불구불하게 만드는데, 이는 결국 **웨이트 값이 커지는 형태**로 나타남

### 실제 관찰: 학습이 진행될수록 웨이트가 계속 커지는 현상

- 실험(베니싱 그라디언트 실험에서 사용했던 네트워크)에서, 로스와 정확도가 거의 변하지 않는 시점(예: 60 에폭) 이후에도 **웨이트 크기는 계속 꾸준히 증가**하는 것이 관찰됨
- 이는 모델이 이미 충분히 학습됐음에도, **트레이닝 데이터에 아주 조금이라도 더 맞추려고 계속 웨이트를 키우는 것** — 이것이 바로 오버피팅으로 이어지는 과정
- → **역으로, 웨이트가 커지지 않도록 잡아주면 오버피팅을 방지할 수 있겠다는 아이디어**가 레귤러라이제이션

## 3. L2 vs L1 레귤러라이제이션의 실제 동작 차이

### 직관적 비유: "웨이트를 망치로 두들기기"

> **웨이트 크기를 두들겨(줄여) 봤을 때, 로스가 별로 안 변하면 → 계속 세게 두들겨서 죽인다 (0에 가깝게)**
> **두들겼는데 로스가 확 커지면 → 그 웨이트는 중요한 웨이트니까 더 이상 줄이지 않는다**

### L2 레귤러라이제이션: 웨이트 크기에 "비례"해서 두들긴다

- 그라디언트를 구해보면, 로스 항에 `2λw` 라는 항이 추가로 붙음
- 이 항은 **웨이트(w) 값에 비례**함 → **웨이트가 큰 놈은 세게, 작은 놈은 살살** 당겨줌(줄여줌)
- 즉, **큰 웨이트일수록 강하게 억제되고, 작은 웨이트는 상대적으로 덜 억제됨**

### L1 레귤러라이제이션: 크든 작든 "공평하게" 두들긴다

- 절댓값을 미분하면 부호만 남음 (`+λ` 또는 `-λ`)
- 즉, **웨이트의 크기와 무관하게 항상 일정한 크기(λ)로 잡아당김**
- 크기가 작은 웨이트도 큰 웨이트와 **똑같은 힘**으로 당겨지기 때문에, **작은 웨이트들이 더 빨리 0으로 소멸**하는 경향이 있음
- → L1은 **많은 연결(커넥션)을 아예 끊어버리고, 중요한 연결만 살리는** 방식에 가까움 (희소성/Sparsity를 유도)

## 4. (심화, 레벨 3) MAP 관점에서 레귤러라이제이션 재해석하기

> 22강에서 배운 MLE(최대우도추정) 관점을 확장한 개념 — **MAP(Maximum A Posteriori, 최대사후확률추정)**

### 기존 MLE와의 차이

- 지금까지는 **라이클리후드 `P(y|W)`를 최대화**하는 W를 찾는 것(MLE)이었음
- MAP는 여기서 한 걸음 더 나가서, **`P(W|y)` (사후확률, Posterior)를 최대화**하는 것

### 베이즈 정리로 관계 파악하기

```
P(W|y) = P(y|W) × P(W) / P(y)
```

| 항 | 이름 |
|---|---|
| `P(y\|W)` | 라이클리후드 (Likelihood) |
| `P(W)` | 프라이어 (Prior, 사전분포) — 웨이트에 대한 "사전 정보/가정" |
| `P(y)` | W와 무관한 상수 (신경 쓸 필요 없음, W의 함수가 아니므로) |
| `P(W\|y)` | 포스테리어 (Posterior, 사후확률) |

> **MAP = 라이클리후드뿐 아니라, "웨이트가 어떤 분포를 따를 것이다"라는 사전 정보(Prior)까지 함께 고려해서 최적의 W를 찾는 것**

### NLL로 전개하면 자연스럽게 레귤러라이제이션이 나온다

- 라이클리후드에 마이너스 로그를 취하면 기존의 NLL(=로스)이 나왔던 것처럼
- MAP에 마이너스 로그를 취하면:
  ```
  -log P(W|y) = NLL(기존 로스) + [-log P(W)]  ← 이 추가된 항이 바로 레귤러라이제이션!
  ```

### Prior를 "가우시안 분포"로 가정하면 → L2 레귤러라이제이션

- `P(W)`를 **평균 0인 가우시안 분포**로 가정하고 `-log`를 전개하면
- `(1/2σ²) × W²` 형태가 남음 → **이것이 바로 L2 레귤러라이제이션!**

### Prior를 "라플라시안 분포"로 가정하면 → L1 레귤러라이제이션

- `P(W)`를 **평균 0인 라플라시안 분포**로 가정하고 전개하면
- 절댓값 형태가 남음 → **이것이 바로 L1 레귤러라이제이션!**

> **결론: L1, L2 레귤러라이제이션은 "웨이트가 평균 0인 어떤 분포(가우시안 or 라플라시안)를 따를 것이다"라는 사전 정보(Prior)를 추가로 준 것일 뿐이다** — 22강에서 배운 "로스는 결국 어떤 분포를 가정했는지의 차이"라는 원리가 여기에도 그대로 적용됨

### λ를 사전분포의 "분산"으로 해석하기

- `λ ∝ 1/(2σ²)` 관계가 성립

| λ 값 | 의미하는 사전분포의 분산 |
|---|---|
| **λ가 작음** | 분산이 **큰** 분포를 가정 → "웨이트가 크게 퍼져 있어도 괜찮다"는 가정 → 웨이트 억제 효과 약함 |
| **λ가 큼** | 분산이 **작은** 분포를 가정 → "웨이트는 0 근처에 몰려 있을 것"이라는 가정 → 웨이트를 0 쪽으로 강하게 당김 |

> 참고: 이 MAP 관점은 강의 전체에서 "몰라도 되지만 알면 더 재밌는" 심화(레벨 3) 내용으로 소개됨

## 5. 실험으로 L2/L1 레귤러라이제이션 비교하기

### 실험 설정: 레귤러라이제이션 미적용 vs L2 적용 vs L1 적용

### 결과 ①: 트레인 로스가 가장 낮은 건 레귤러라이제이션 미적용

> **트레인 로스를 줄이는 게 능사가 아니다** (앞서 여러 번 강조된 원칙)

- 레귤러라이제이션을 적용하지 않았을 때 **트레인 로스는 가장 낮게 나옴**
- 하지만 **밸리데이션 로스는 오히려 가장 나쁘게(높게)** 나옴 — 전형적인 오버피팅
- L2, L1을 적용했을 때는 트레인 로스가 상대적으로 덜 낮아지지만(=너무 억지로 맞추지 않음), **밸리데이션 로스는 더 좋게** 나타남 → 실제 목표(테스트/실전 성능)에는 레귤러라이제이션이 더 유리함

### 결과 ②: 웨이트 크기의 학습 곡선으로 L1/L2 차이 확인

- 레귤러라이제이션 미적용: 웨이트 크기가 계속 커지는 모습
- L2 적용: 큰 웨이트는 빠르게, 작은 웨이트는 천천히 줄어드는 모습 (예: 특정 웨이트가 이미 작아서 이후로는 거의 안 줄어드는 패턴)
- L1 적용: 크기와 무관하게 일정한 속도로 꾸준히 줄어드는 모습 (특정 웨이트가 결국 완전히 소멸하는 모습도 관찰됨)
- → 이는 앞서 설명한 "L2는 크기 비례, L1은 균등하게 당김"이라는 이론적 차이를 실제 실험에서도 확인할 수 있었음

## 6. 오버피팅 방지 방법 총정리

강의 전체에서 다룬 오버피팅 방지 기법들을 한데 모으면:

| 방법 | 핵심 아이디어 |
|---|---|
| **모델 단순화** | 문제에 비해 너무 복잡한 모델을 사용하지 않기 |
| **데이터 확보 / 데이터 어그멘테이션** | 데이터를 최대한 많이 모으거나, 기존 데이터를 변형해 늘리기 (가장 근본적이고 중요) |
| **얼리 스타핑 (Early Stopping)** | 밸리데이션 데이터 기준으로 성능이 가장 좋을 때의 모델을 저장하고 그 이후로는 학습을 멈춤 (15강에서 다룬 밸리데이션 개념과 연결) |
| **드랍아웃 (Dropout)** | 학습 중 노드를 랜덤하게 탈락시켜 코어댑테이션을 방지 (29강) |
| **드랍 커넥트 (DropConnect)** | 드랍아웃과 비슷하지만, 노드가 아니라 **커넥션(연결) 자체**를 랜덤하게 끊는 방식 (실무에서는 드랍아웃이 더 많이 사용됨) |
| **레귤러라이제이션 (L1, L2)** | 로스에 웨이트 크기를 추가해서, 웨이트가 과도하게 커지지 않도록 억제 (이번 강의) |

## 7. 강의 시리즈를 마치며

- 이번 강의를 끝으로 기초 딥러닝 개념(AI/ML/DL 정의부터 오버피팅 방지까지)에 대한 시리즈가 마무리됨
- 이후 내용(CNN, RNN, Attention 등)은 강사의 다른 강의 시리즈(AI 딥다이브)에서 이어서 다룰 예정이라고 언급됨

## 8. 이번 강의 핵심 요약

- [x] **레귤러라이제이션**: 로스에 웨이트 크기(`λ × ||W||_p`)를 더해서, 불필요하게 큰 웨이트를 억제하는 기법
- [x] 웨이트가 클수록 모델이 표현하는 함수가 더 복잡(꼬불꼬불)해지고, 이는 오버피팅과 연결됨 — 실제로 학습이 진행될수록 웨이트가 계속 커지는 현상이 관찰됨
- [x] **L2 레귤러라이제이션**: 웨이트 크기에 비례해서 억제 (큰 웨이트는 강하게, 작은 웨이트는 약하게)
- [x] **L1 레귤러라이제이션**: 웨이트 크기와 무관하게 균등한 힘으로 억제 → 작은 웨이트들을 더 빨리 소멸시켜 희소성(Sparsity)을 유도
- [x] (심화) **MAP 관점**: 레귤러라이제이션은 "웨이트가 평균 0인 특정 분포(가우시안→L2, 라플라시안→L1)를 따를 것"이라는 사전 정보(Prior)를 추가한 것으로 재해석 가능
- [x] 실험 결과: 레귤러라이제이션 미적용 시 트레인 로스는 가장 낮지만 밸리데이션 로스는 가장 나쁨(오버피팅) — L1/L2 적용 시 밸리데이션 성능이 개선됨
- [x] **오버피팅 방지 방법 총정리**: 모델 단순화, 데이터 확보/어그멘테이션, 얼리 스타핑, 드랍아웃/드랍커넥트, L1/L2 레귤러라이제이션
- [x] 이 강의 시리즈는 여기서 마무리되며, CNN/RNN/Attention 등 후속 내용은 별도 강의 시리즈에서 다룸

## 용어 정리

| 용어 | 의미 |
|---|---|
| 레귤러라이제이션 (Regularization) | 로스에 웨이트 크기를 추가해 오버피팅을 방지하는 기법 |
| 놈 (Norm) | 벡터의 크기를 나타내는 방법 (L1놈=절댓값의 합, L2놈=제곱합의 제곱근) |
| L1 레귤러라이제이션 | 웨이트 크기와 무관하게 균등한 힘으로 억제, 희소성을 유도 |
| L2 레귤러라이제이션 | 웨이트 크기에 비례해서 억제 |
| MAP (Maximum A Posteriori) | 라이클리후드뿐 아니라 사전분포(Prior)까지 고려해 최적 파라미터를 찾는 방법 |
| 프라이어 (Prior, 사전분포) | 파라미터(웨이트)에 대해 미리 가정하는 확률분포 |
| 포스테리어 (Posterior, 사후확률) | 데이터를 관측한 후 갱신된 파라미터에 대한 확률분포 |
| 얼리 스타핑 (Early Stopping) | 밸리데이션 성능이 가장 좋을 때 학습을 멈추고 그 모델을 저장하는 기법 |
| 드랍 커넥트 (DropConnect) | 노드가 아닌 커넥션(연결) 자체를 랜덤하게 끊는 드랍아웃의 변형 |
