# 6강. 인공신경망은 함수다

> 딥러닝 강의 6강 정리 노트

---

## 1. 핵심 명제: 인공신경망은 함수다

> **인공신경망 = 함수(Function)**

### 함수란 무엇인가? (복습)

- 뭔가를 넣으면(입력) 뭔가가 튀어나오는(출력) 것
- 예: `f(x) = x²`
  - `x=1` 입력 → `1` 출력
  - `x=2` 입력 → `4` 출력
  - `x=-2` 입력 → `4` 출력
- 입력이 여러 개일 수도 있음: `f(x, y) = y × x²`
  - `(1,1)` 입력 → `1` 출력
  - `(2,1)` 입력 → `4` 출력
- 여러 개가 들어가서 여러 개가 나올 수도 있음 → 이것도 함수 개념에 부합

### 인공신경망도 똑같은 "함수"일 뿐

- 인공신경망: 뭔가(x)를 넣으면 → 뭔가(y)가 튀어나옴
- **웨이트를 곱하고, 바이어스를 더하고, 액티베이션을 통과시키는 구성 요소들로 이루어진 함수**일 뿐
- 특별한 새로운 수학적 개념이 아니라, 그냥 "함수"

---

## 2. "때려넣는다"는 것의 재해석 = 입출력 쌍을 계속 알려주는 것

- 이전 강의들에서 "강아지 사진 넣으면 1, 고양이 사진 넣으면 0" 처럼 데이터를 "때려넣는다"고 표현했음
- 이걸 함수 관점에서 다시 보면:
  - 이 함수(인공신경망)에게 **입력-출력 쌍(pair)을 계속 알려주는 것**
  - 완전 주입식 교육: "이거 핸드폰이야", "이것도 핸드폰이야"를 계속 알려주면 결국 "핸드폰이 뭔지" 깨닫게 되는 것과 같은 원리

### 수학적으로 다시 말하면

> **AI가 학습한다 = 입력과 출력을 연결하는 함수를 알아낸다**

- 다양한 `(x, y)` 쌍(정답이 있는 데이터)을 계속 보여주다 보면
- 함수 `f` 속에 들어있는 **웨이트와 바이어스**를 AI가 스스로 알아냄

---

## 3. 예시로 이해하기: 조회수 vs 수익 예측 (다음 강의 예고 겸 프리뷰)

- x축 = 유튜브 조회수, y축 = 수익
- 여러 데이터(조회수-수익 쌍)를 모아봄 (완벽하게 일직선은 아님 — 영상 길이 등 다른 요인도 있음)
- 이 데이터를 계속 AI에게 보여주면, **그 사이를 잇는 함수를 찾아냄**
- 학습이 끝나면, **처음 보는 조회수**를 입력했을 때도 적절한 수익을 예측할 수 있게 됨

### GPT도 같은 원리

- "이 말에는 이렇게 답한다"는 예시를 수백만 번 학습
- → **언어에 대한 함수를 찾아낸 것**
- 처음 보는 질문에도 적절히 답하는 이유 = 그 함수를 잘 찾았기 때문
- (참고: 실제로는 여기에 사람의 피드백(RLHF 등)이 일부 관여하지만, 기본 원리는 동일)

> **결론: AI는 결국 거대한 함수다. 학습이란 그 함수를 찾는 과정이다.**

---

## 4. 딥러닝의 목표 = 웨이트와 바이어스를 알아내는 것

- 인공신경망(함수)을 표현할 때, 그 안에 들어가는 요소는:
  - 웨이트(Weight)
  - 바이어스(Bias)
  - 액티베이션(Activation, 구조상 미리 정해둠)
- **딥러닝의 목표를 한 문장으로 요약하면:**
  > **"적절한 웨이트와 바이어스 값을 알아내는 것"**

---

## 5. 인공신경망으로 1차 함수 만들어보기

### 새로운 개념: Linear Activation (선형 활성화 함수)

> **Linear Activation = 들어온 대로 그대로 나가는 함수**
> 즉, `y = x` 꼴의 함수

- 지금까지 배운 Unit Step Function과 달리, 값을 변형하지 않고 그대로 통과시킴

### 1차 함수 `ax + b`를 인공신경망으로 표현하기

```
입력 x
  → 웨이트 a를 곱함 (a × x)
  → 바이어스 b를 더함 (a × x + b)
  → Linear Activation 통과 (그대로 통과, 값 변화 없음)
  → 출력: ax + b
```

- **웨이트 = a**
- **바이어스 = b**
- Linear Activation을 사용하면 인공신경망 하나로 **1차 함수 `ax + b`를 그대로 표현**할 수 있음

> 인공신경망은 결국 `ax + b`를 나타내는 신경망일 수도 있다 — 이렇게 간단한 구조도 "1차 함수를 표현하는 함수"인 것

---

## 6. 다음 강의 예고: 선형회귀 (Linear Regression)

- 이 간단한 1차 함수 구조를 가지고 **선형회귀(Linear Regression)**를 설명할 예정
- 강사 표현: *"선형회귀를 이해하면 딥러닝을 이해할 수 있다"* — 딥러닝의 축소판이라 할 만큼 중요한 개념
