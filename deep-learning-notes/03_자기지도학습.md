# 3강. 자기지도학습 (Self-supervised Learning)

> 딥러닝 강의 3강 정리 노트

---

## 1. 지도학습의 문제점: 정답 만드는 비용

- 지도학습은 정답(레이블)을 알고 있는 데이터가 많을수록 좋음
- 하지만 **정답을 만드는 데 비용이 많이 듦**
  - 예: 이미지에 "사람이 어디 있는지" 표시하는 작업을 외부 업체에 맡겨야 할 정도
- 이런 한계 때문에 등장한 것이 **자기지도학습(Self-supervised Learning)**
  - (참고: 준지도학습(Semi-supervised Learning)도 방식은 다르지만 같은 문제의식에서 출발)

---

## 2. 자기지도학습의 핵심 개념

> **진짜 풀려는 문제 말고, 가짜 문제를 새로 정의해서 먼저 풀어보는 것**

- 레이블이 없는 데이터(예: 그냥 인터넷에서 가져온 사진)는 지도학습에서는 못 쓰고 버려야 함
- 자기지도학습은 이런 레이블 없는 데이터도 활용 가능
- **셀프로 정답을 만들어서** 학습 → 그래서 이름이 "자기지도(Self-supervised)"

### 비유: 스스로 문제 만들어 풀기
- 학습지처럼 정답이 이미 있는 문제 = 지도학습
- 시중 문제집을 다 풀어서 더 이상 데이터(문제)가 없을 때, 내가 직접 문제를 만들어서 풀어보는 것 = 자기지도학습

---

## 3. 예시 ①: Context Prediction (상대적 위치 예측)

논문 기반 예시 (개념 이해용, 유일한 방법은 아님)

### 가짜 문제 만드는 방법
1. 사진에서 **패치(patch, 작은 조각)** 위치를 랜덤하게 하나 잡음 (예: 파란색 패치)
2. 그 주변에 같은 크기의 패치들을 상대적 위치별로 정의 (1~8번 위치)
3. 파란색 패치 + 주변 패치 하나를 모델에 입력
4. **두 패치의 상대적 위치(1~8 중 하나)를 출력하도록 학습**

- 레이블이 없는 사진이어도, 이 방식으로는 정답(상대적 위치)을 스스로 만들 수 있음 → 무한히 학습 가능

### 왜 이게 효과가 있을까?
- 이미지 속 세상은 픽셀이 무작위로 배치된 게 아니라 **연속적인 맥락**을 가짐
  - 예: 얼굴이 있으면 귀가 있고, 귀 옆에 볼이 있고... (고양이면 몸통 옆에 다리, 꼬리 등)
- 상대적 위치를 맞히는 연습을 하다 보면 자연스럽게 **이미지의 맥락/구조를 이해하는 능력**이 길러짐

### 효과 검증
- 정답 있는 데이터가 100개밖에 없다고 가정
- ① 그냥 100개로만 학습 vs ② 가짜 문제(상대적 위치 예측)로 먼저 학습 후 100개로 추가 학습
- → **②가 훨씬 성능이 좋음** — 이것이 자기지도학습의 출발점

## 4. 자기지도학습의 용어 정리

| 용어 | 의미 |
|---|---|
| **프리텍스트 태스크 (Pretext Task)** | 스스로 만든 가짜 문제 (예: 상대적 위치 맞히기) |
| **프리트레이닝 (Pre-training)** | 프리텍스트 태스크로 미리 학습시키는 것 = 사전학습 |
| **다운스트림 태스크 (Downstream Task)** | 진짜로 풀고 싶은 문제 (레이블 있는 데이터로 학습) |
| **트랜스퍼 러닝 (Transfer Learning)** | 사전학습된 모델을 새로운(진짜) 문제에 맞게 이어서 학습시키는 것 |

### 학습 흐름
```
1단계: 프리텍스트 태스크 풀이 (가짜 문제) → 프리트레인 모델 생성
2단계: 다운스트림 태스크 풀이 (진짜 문제, 레이블 있는 데이터) → 트랜스퍼 러닝
```

- 기존 지도학습: 2단계만 수행
- 자기지도학습: **1단계를 먼저 하고 2단계** → 성능이 더 좋아짐

### 트랜스퍼 러닝 시 모델 구조

- 가짜 문제(예: 8개 위치 중 하나 예측)와 진짜 문제(예: 강아지/고양이 분류, 0 or 1)는 출력 형태가 다름
- → 인공신경망의 **맨 마지막 층만 교체**해서 새로운 출력 형태에 맞게 수정
- "전이(Transfer)"라고 부르는 이유: 완전히 다른 문제를 푸는 게 아니라, 비슷한 입력 데이터에 대해 학습한 지식을 새 문제로 옮겨서 활용하기 때문

> 참고: 이 예시 논문은 이 가짜 문제에 **"Context Prediction"**이라는 이름을 붙임 (문장에 맥락이 있듯, 이미지에도 맥락이 있다는 의미)

## 5. 예시 ②: Contrastive Learning (대조 학습) — 가장 널리 쓰이는 방식

개념은 Context Prediction보다 오히려 더 단순하지만, 훨씬 강력해서 실무에서 많이 쓰임.

### 학습 과정

하나의 CNN 모델을 사용 (모델은 하나, 여러 입력을 순서대로/동시에 넣는 것)

1. **사진 1**에서 일부분을 떼서 변형 → 모델에 입력 → 출력 `1'` (벡터)
2. **같은 사진 1**에서 또 다른 부분을 랜덤하게 떼서 → 모델에 입력 → 출력 `2'`
3. **다른 사진(사진 2)**에서 일부분을 떼서 → 모델에 입력 → 출력 `3'`
4. 같은 다른 사진에서 또 다른 부분을 떼서 → 모델에 입력 → 출력 `4'`

### 학습 목표 (핵심 규칙)

| 관계 | 목표 |
|---|---|
| `1'`과 `2'` (같은 원본 사진 출처) | **값이 비슷하게** 나오도록 학습 |
| `1'`과 `3'` (다른 원본 사진 출처) | **값이 최대한 멀게(다르게)** 나오도록 학습 |
| `1'`과 `4'` (다른 원본 사진 출처) | **값이 최대한 멀게(다르게)** 나오도록 학습 |

> **한 줄 요약**: 출처가 같은 사진(조각)은 비슷한 값이 나오게, 출처가 다른 사진은 최대한 먼 값이 나오게 학습시키는 기법 = **Contrastive Learning**

- 어떤 클래스인지까지는 몰라도 됨 — 그냥 "같은 사진에서 왔는지 / 다른 사진에서 왔는지"만 알면 됨
- 레이블이 전혀 필요 없기 때문에 자기지도학습으로 분류됨

## 6. 예시 ③: GPT와 BERT도 자기지도학습

### GPT — Next Token Prediction (다음 단어 예측)
- 문장의 앞부분만 보여주고 다음 단어를 예측하게 학습
  - 1번째 단어 → 2번째 단어 예측
  - 1~2번째 단어 → 3번째 단어 예측
  - ... 반복
- 그냥 문장 데이터만 있으면 되고, 별도의 레이블이 필요 없음
- GPT 개발자의 표현: Next Token Prediction은 **"world model"** — 세상을 이해하는 방법
  - 검색엔진처럼 정보를 긁어와서 복사-붙여넣기 하는 게 아니라, 세상을 이해한 상태로 말하는 것

### BERT — 빈칸 채우기 (Masked Language Model)
- 문장에 빈칸(마스킹)을 뚫어놓고, 그 빈칸에 들어갈 단어를 예측하게 학습
- 마찬가지로 정답(레이블)이 별도로 필요 없음 → 자기지도학습

## 7. 이번 강의 핵심 요약

- [x] 지도학습의 한계: 레이블링 비용이 큼
- [x] 자기지도학습 = **가짜 문제(프리텍스트 태스크)를 스스로 만들어 먼저 풀어보는 것**
- [x] 학습 흐름: 프리트레이닝(가짜 문제) → 트랜스퍼 러닝(진짜 문제, 마지막 층만 교체)
- [x] **Context Prediction**: 이미지 패치의 상대적 위치를 맞히는 가짜 문제
- [x] **Contrastive Learning**: 같은 출처는 가깝게, 다른 출처는 멀게 — 가장 널리 쓰이는 방식
- [x] **GPT** = 다음 단어 예측 방식의 자기지도학습
- [x] **BERT** = 빈칸 채우기 방식의 자기지도학습

## 용어 정리

| 용어 | 의미 |
|---|---|
| 자기지도학습 (Self-supervised Learning) | 스스로 만든 가짜 문제로 학습하는 방식 |
| 프리텍스트 태스크 (Pretext Task) | 스스로 정의한 가짜 문제 |
| 프리트레이닝 (Pre-training) | 가짜 문제로 미리 학습시키는 것 (사전학습) |
| 다운스트림 태스크 (Downstream Task) | 최종적으로 풀고 싶은 진짜 문제 |
| 트랜스퍼 러닝 (Transfer Learning) | 사전학습 모델을 새 문제에 맞게 이어서 학습 (전이학습) |
| 컨트라스트 러닝 (Contrastive Learning) | 같은 출처는 가깝게, 다른 출처는 멀게 학습시키는 대조 학습 기법 |
| Next Token Prediction | GPT의 학습 방식 — 다음 단어를 예측 |
| Masked Language Model | BERT의 학습 방식 — 빈칸에 들어갈 단어를 예측 |
