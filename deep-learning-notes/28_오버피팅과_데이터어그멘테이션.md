# 28강. 오버피팅(Overfitting)과 데이터 어그멘테이션

> 딥러닝 강의 28강 정리 노트

---

## 1. 오버피팅이란? (복습 + 명확한 정의)

### 예시: 조회수-수익 예측

- 단순한 인공신경망 → 조회수-수익 관계를 적당히 파악 (초록색 선)
- 매우 복잡한 인공신경망 → **트레이닝 데이터에 대해서는 완벽하게(로스=0) 예측**하지만, 곡선이 지나치게 구불구불함 (파란색 선)

### 오버피팅의 정확한 정의

> **트레이닝 때는 잘하는데, 테스트 때는 못하는 것**

- 파란색(복잡한 모델)이 트레이닝 데이터는 완벽히 맞히지만, 처음 보는 테스트 데이터에서는 초록색(단순한 모델)보다 오히려 **에러가 더 큼**
- 즉, 상대적으로 **파란색 쪽이 오버피팅이 더 심하게 일어난 상태**

> 참고: 27강에서 다룬 "56층이 20층보다 트레이닝 에러조차 나쁜 경우"는 오버피팅이 아니었음 — 오버피팅은 반드시 "트레이닝은 잘하지만 테스트를 못하는" 패턴이어야 함

---

## 2. 오버피팅의 두 가지 원인과 각각의 해결책

### 원인 ①: 모델이 문제에 비해 너무 복잡함

> **해결책: 모델을 더 단순하게 만든다**

- 입력-출력 관계를 필요 이상으로 복잡하게 표현하고 있다면, 더 단순한 구조로도 충분할 수 있음

### 원인 ②: 데이터가 너무 적음

> 이 경우는 훨씬 까다로운 상황

- 데이터가 적으면, 모델을 아무리 단순하게 바꿔도 근본적으로 해결이 안 될 수 있음
- 예: 데이터 포인트가 몇 개 없는 상태에서는, 단순한 모델(초록색)이든 복잡한 모델(파란색)이든 둘 다 **새로운(있을 법한) 데이터에 대해 큰 에러**를 낼 수 있음
- → **모델 구조를 바꾸는 것만으로는 해결되지 않는 문제**

> **결론: 데이터를 충분히 확보하는 것이 오버피팅 방지의 가장 근본적이고 중요한 해결책**

- 베니싱 그라디언트 같은 문제는 ReLU, 배치 정규화 등 "신경망 자체의 기법"으로 어느 정도 해결할 수 있었지만
- **데이터 부족 문제는 신경망 구조를 아무리 잘 설계해도 근본적으로 한계가 있음** — 결국 데이터 자체가 좋아야 함

## 3. 데이터가 부족할 때의 대안: 데이터 어그멘테이션 (Data Augmentation)

### 왜 필요한가?

- 데이터를 무한정 새로 모으기 어려운 상황이 있음 (예: **의료 데이터**는 데이터 확보 자체가 매우 어려움)
- 이럴 때 **기존에 가진 데이터를 변형해서 마치 여러 개의 새로운 데이터처럼 활용**하는 기법이 데이터 어그멘테이션

### 핵심 아이디어: "본질이 바뀌지 않는 변형"을 가해서 데이터를 늘린다

> **강아지 사진을 돌리거나, 잘라도 여전히 "강아지"라는 사실은 변하지 않는다**

- 원본 강아지 사진 하나를 가지고:
  - 회전시킨 사진
  - 일부를 자른(크롭) 사진
  - 등등 다양하게 변형
- 이 변형된 사진들에도 **똑같이 "강아지" 레이블을 부여**해서 학습에 사용

### 효과: 데이터 한 장으로 여러 장의 효과를 낸다

- 예: 원본 1장 + 변형 9가지 = 총 10장처럼 활용 가능
- 당연히 **실제로 다양하게 촬영된 진짜 10장보다는 성능이 떨어짐** — 하지만 그냥 원본 1장만 쓰는 것보다는 **오버피팅을 훨씬 잘 방지**할 수 있음

### 회귀(Regression) 문제에서의 비유

- 조회수-수익 예시에서도, 데이터에 적절한 노이즈나 변형을 주는 어그멘테이션을 하면
- 실제 있을 법한 다양한 상황을 미리 반영해서, 오버피팅 없이 좀 더 합리적인(일반화가 잘 되는) 곡선을 학습할 가능성이 높아짐

---

## 4. 어그멘테이션의 다양한 기법들 (특히 의료 이미지 분야)

> 의료 데이터는 확보가 어려운 대표적인 분야라, 데이터 어그멘테이션 기법이 특히 많이 발전함

### 그리드 디스토션 (Grid Distortion)

- 원본 이미지를 격자(그리드)로 나눈 뒤, 그 격자를 뒤틀어서 변형

### 엘라스틱 트랜스폼 (Elastic Transform)

- 이미지를 마치 고무처럼 **흐물흐물하게** 왜곡시키는 변형
- 예: 세포 이미지 분할(세그멘테이션) 문제에서 유용
  - 세포는 항상 동그란 모양이 아니라 다양하고 불규칙한(꾸물꾸물한) 형태를 가짐
  - 엘라스틱 트랜스폼으로 이런 다양한 형태 변형에도 잘 대응하도록 학습시키면, 실제 다양한 세포 모양을 더 잘 분할(세그멘테이션)할 수 있게 됨
- 활용 예: 뇌종양이 어디 있는지 찾아내는 의료 영상 세그멘테이션 등

## 6. 이번 강의 핵심 요약

- [x] **오버피팅의 정의**: 트레이닝 때는 잘하지만 테스트 때는 못하는 것 (반드시 이 패턴이어야 오버피팅)
- [x] **원인 ① 모델이 너무 복잡함** → 해결책: 모델을 단순화
- [x] **원인 ② 데이터가 너무 적음** → 해결책: 모델 구조 변경으로는 근본 해결이 안 되며, **데이터를 많이 확보하는 것이 가장 중요**
- [x] 데이터를 추가로 모으기 어려운 상황(예: 의료 데이터)에서는 **데이터 어그멘테이션**으로 대응
- [x] 어그멘테이션의 핵심 원리: **"본질(레이블)이 변하지 않는 변형"**을 가해서 데이터를 마치 여러 장처럼 활용 (회전, 크롭 등)
- [x] 실제 다양한 데이터보다는 성능이 떨어지지만, 아예 어그멘테이션을 안 하는 것보다는 오버피팅 방지에 훨씬 효과적
- [x] 의료 영상 분야에서는 **그리드 디스토션, 엘라스틱 트랜스폼** 등 정교한 어그멘테이션 기법이 발전되어 있음 (세포 등 불규칙한 형태를 다루는 세그멘테이션에 특히 유용)
- [x] 다음 강의 예고: **드랍아웃(Dropout)** — 오버피팅 방지의 또 다른 대표 기법

---

## 용어 정리

| 용어 | 의미 |
|---|---|
| 오버피팅 (Overfitting) | 트레이닝 데이터에는 잘 맞지만 테스트(새로운) 데이터에는 성능이 떨어지는 현상 |
| 데이터 어그멘테이션 (Data Augmentation) | 기존 데이터를 변형해 마치 여러 개의 새로운 데이터처럼 늘려서 활용하는 기법 |
| 그리드 디스토션 (Grid Distortion) | 이미지를 격자로 나눠 뒤트는 어그멘테이션 기법 |
| 엘라스틱 트랜스폼 (Elastic Transform) | 이미지를 고무처럼 흐물흐물하게 왜곡하는 어그멘테이션 기법 |
| 드랍아웃 (Dropout) | 오버피팅 방지를 위한 또 다른 기법 (다음 강의 예정) |
