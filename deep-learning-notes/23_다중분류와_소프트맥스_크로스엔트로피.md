# 23강. 다중 분류(Multi-class Classification)와 소프트맥스, 크로스 엔트로피

> 딥러닝 강의 23강 정리 노트 — 챕터 4 마무리 및 전체 요약

---

## 1. 다중 분류 문제 설정: 강아지/고양이/소 분류

- 입력: `3×100×100` 사진 (강아지, 고양이, 소 사진만 넣음)
- 출력: **3개 노드** (강아지 확률, 고양이 확률, 소 확률)
- 이진 분류가 "동전 뒤집기"처럼 확률값 하나로 충분했다면, 다중 분류는 **클래스 개수만큼의 출력**이 필요

### 파라미터 개수 계산

```
입력 픽셀 수 = 3×100×100 = 30,000개
웨이트 = 30,000 × 3(출력 노드 수) = 90,000개
바이어스 = 3개 (노드가 3개이므로)
총 파라미터 = 90,003개
→ 그라디언트의 길이도 90,003
```

- 계산 방식 자체는 이전과 완전히 동일 — **결국 로스만 잘 정의하면 나머지는 똑같은 딥러닝 수식(그라디언트 디센트)을 그대로 적용**

---

## 2. 목표: "각 노드가 각 동물을 담당하게 만들기"

### 레이블 설계: 원-핫 인코딩(One-hot Encoding)

- 출력이 3개니까 레이블도 3개의 값으로 구성
  - 강아지 사진 → 레이블 `(1, 0, 0)`
  - 고양이 사진 → 레이블 `(0, 1, 0)`
  - 소 사진 → 레이블 `(0, 0, 1)`

> **로스를 "출력이 이 레이블에 가까워질수록 작아지게" 설계하면, 자연스럽게 각 노드가 각 동물의 확률을 담당하게 됨**

- 예: 강아지 사진을 넣었는데 (0.5, 0.5, 0)처럼 애매하게 나오면 로스가 커지도록 설계 → 모델은 첫 번째 노드를 1에 가깝게 만들려고 학습됨 → 결과적으로 **첫 번째 노드 = 강아지 확률**이 되는 것

## 3. 새로운 활성화 함수: 소프트맥스 (Softmax)

### 왜 필요한가?

- 레이블 `(1,0,0)` 등은 사실 **확률 분포**임 (한 곳만 1이고 나머지는 0)
- 그렇다면 신경망의 출력도 **확률 분포**처럼 나와야 함 — 즉, 출력들의 **합이 1**이 되고 **모두 양수**여야 함
- 이런 조건을 만족시켜주는 활성화 함수가 바로 **소프트맥스**

### 소프트맥스의 구조 (기존 액티베이션과 다른 점)

- 지금까지의 활성화 함수(시그모이드 등)는 **각 노드마다 독립적으로** 동그라미 하나에 적용됐음
- 소프트맥스는 **여러 출력값(L1, L2, L3)을 전부 함께 사용**해서 계산하기 때문에, 동그라미가 아니라 **네모 상자**로 표현

### 수식

```
입력: L1, L2, L3 (Linear Activation을 거친 값 = 로짓)

Q1 = e^L1 / (e^L1 + e^L2 + e^L3)
Q2 = e^L2 / (e^L1 + e^L2 + e^L3)
Q3 = e^L3 / (e^L1 + e^L2 + e^L3)
```

- **분모는 공통** (모든 로짓의 exponential 합)
- **분자는 자기 자신의 exponential**

### 소프트맥스가 확률 분포 조건을 만족하는 이유

| 조건 | 만족 여부 |
|---|---|
| 합이 1 | 분모가 공통이므로 통분 불필요 → 세 분자를 더하면 자연스럽게 분모와 같아져서 합이 1 |
| 모두 양수 | exponential 함수는 항상 양수를 출력하므로 자동 만족 |

---

## 4. 왜 하필 소프트맥스인가? — 다른 함수와 비교해보기

### 비교 ①: 절댓값을 이용한 함수 (`|Li| / Σ|Li|`)

- 이것도 "합이 1, 모두 양수" 조건은 만족함
- **하지만 문제가 있음**: 절댓값은 부호(양수/음수)를 구별하지 못함
  - 예: `(L1,L2,L3) = (1,1,1)` 이든 `(-1,-1,-1)` 이든 → 결과가 똑같이 `(1/3, 1/3, 1/3)`으로 동일하게 나옴
  - 즉, **입력 공간에서 부호만 반대인 지점들이 전부 같은 출력을 내버림** (일종의 "데칼코마니"처럼 값이 중복됨)
  - 이는 **표현할 수 있는 정보의 절반이 낭비되는 것**과 같음 (양수/음수 구별을 못 하니, 사실상 1/8 공간만 유효하게 쓰임 — 3차원 기준)
- 소프트맥스는 exponential 함수를 쓰기 때문에 **양수/음수를 명확히 구별**함 (음수를 넣으면 결과가 작아지고, 양수를 넣으면 결과가 커짐) → 이런 중복 문제가 없음

### 비교 ②: 각 노드에 시그모이드를 따로 적용하는 방법

- 이 경우 **합이 1이 된다는 보장이 없음** (예: 0.5, 0.5, 0.5처럼 나올 수 있음)
- 다중 분류는 **"이거 아니면 저거"** 식으로 딱 하나를 골라줘야 하는 문제인데, 합이 1이 아니면 이런 "배타적 선택"을 표현하기 어려움
- → 다중 분류에는 소프트맥스가 더 적합

### 그렇다면 시그모이드는 언제 쓰나? — 멀티레이블 분류(Multi-label Classification)

> **다중 분류(Multi-class)와 멀티레이블 분류(Multi-label)는 다른 문제!**

| 구분 | 의미 | 예시 |
|---|---|---|
| **다중 분류 (Multi-class)** | 여러 클래스 중 **딱 하나**를 선택 | "이 사진은 강아지냐 고양이냐 소냐" |
| **멀티레이블 분류 (Multi-label)** | 사진에 존재하는 **모든 대상을 각각** 판별 (동시에 여러 개가 참일 수 있음) | "이 사진에 고양이도 있고 새도 있다" |

- 멀티레이블 분류에서는 각 클래스가 서로 배타적이지 않으므로(하나가 커져도 다른 게 작아질 필요가 없으므로), **각 노드에 독립적으로 시그모이드를 적용**하는 것이 적절함

## 5. 다중 분류의 로스: 크로스 엔트로피 (Cross Entropy)

### 이진 분류와 같은 논리: 레이블의 분포를 가정하기

- 이진 분류: 레이블이 **베르누이 분포**를 따른다고 가정 → BCE
- 다중 분류: 레이블이 **멀티누이 분포(Multinoulli / Categorical Distribution, 베르누이의 확장판)**를 따른다고 가정 → **크로스 엔트로피(Cross Entropy)**

### 멀티누이 분포의 수식

```
P(y) = Q1^y1 × Q2^y2 × Q3^y3
```

- 원-핫 레이블이 `(1,0,0)`이면 → 대입 시 `Q1`만 남음
- `(0,1,0)`이면 → `Q2`만 남음
- `(0,0,1)`이면 → `Q3`만 남음

> 이 수식은 베르누이 분포 수식(`Q^y × (1-Q)^(1-y)`)을 **클래스가 2개에서 3개(또는 그 이상)로 확장한 것**과 동일한 구조

### NLL(Negative Log-Likelihood)로 전개 → 크로스 엔트로피

```
Cross Entropy Loss = -Σ (y_i × log(Q_i))   (각 클래스 i에 대해)
```

- 원-핫 인코딩이므로, 실제로 로스 계산에 **기여하는 항은 정답 클래스에 해당하는 딱 하나뿐**
  - 예: 강아지 사진(y=(1,0,0))이면 → `-log(Q1)` 만 남고, 나머지 항은 y값이 0이라서 전부 사라짐

### 신기한 포인트: "정답 노드만 신경 쓰면 나머지는 저절로 해결된다"

> **강아지 사진일 때는 그냥 Q1만 1에 가깝게 만들면 되고, 나머지 출력(Q2, Q3)은 로스 수식에 아예 포함되지도 않는다!**

- 어떻게 이게 가능한가? → **소프트맥스 덕분**
- 소프트맥스는 출력의 **합이 항상 1**이 되도록 강제하는 구조이므로, **한 노드를 1에 가깝게 만들면 나머지는 자동으로 0에 가깝게 밀려남**
- 즉, "정답 노드 하나만" 신경 써도 나머지가 저절로 따라옴 (소프트맥스와 크로스 엔트로피가 짝을 이루는 이유)

---

## 6. 크로스 엔트로피와 엔트로피의 관계 (보충 개념)

### 성질: 크로스 엔트로피는 항상 엔트로피보다 크거나 같다

```
Cross Entropy(y, Q) ≥ Entropy(y)
```

- 엔트로피는 크로스 엔트로피 수식에서 `Q` 자리에 `y`(정답 분포 자기 자신)를 대입한 것과 같음
- **크로스 엔트로피를 계속 줄이다 보면, 결국 `Q`가 `y`와 같아지는 지점(=엔트로피 값)에 도달**하게 됨
- 즉, 크로스 엔트로피를 최소화하는 것 = **신경망 출력 분포(Q)를 정답 분포(y)에 최대한 가깝게 만드는 것**

### 이진 분류로 돌아가서 검증해보기

- 다중 분류의 소프트맥스+크로스 엔트로피 방식을 클래스가 2개인 경우(이진 분류)로 좁혀서 전개해보면
- 정확히 이전에 배운 **Binary Cross Entropy 수식과 동일한 결과**가 나옴
- → **BCE는 사실 Cross Entropy의 특수한(2-클래스) 경우였다는 것을 다시 확인**

## 7. 심화: 다중 분류도 "로지스틱 회귀"처럼 재해석 가능

- 이진 분류를 "리니어 액티베이션(로짓) → 시그모이드(확률 변환)"로 나눠서 봤던 것처럼
- 다중 분류도 **"신경망은 로짓(L1, L2, L3)까지만 만들고, 그 뒤(소프트맥스, 크로스 엔트로피)는 로스를 구하기 위한 과정"**으로 해석 가능
- 이런 방식을 **멀티노미얼 로지스틱 회귀(Multinomial Logistic Regression)** 또는 **소프트맥스 회귀(Softmax Regression)**라고 부름

### 실무 팁: PyTorch의 `nn.CrossEntropyLoss` 관련 주의사항

> **`nn.CrossEntropyLoss`는 내부에 소프트맥스가 이미 포함되어 있음!**

- 그래서 모델을 만들 때 **소프트맥스를 직접 추가하면 안 됨** (중복 적용되어 버림)
- 이런 설계를 한 이유는 "신경망의 역할 = 로짓을 만드는 것까지"라는 관점과 맞닿아 있음
- 또 다른 실무적 이유: 회귀와 분류를 동시에 풀어야 하는 경우(예: Object Detection)에는, 출력의 일부는 소프트맥스를 적용하고 일부는 그대로 둬야 하는데, 모델 구조에서 이걸 나누는 것보다 **로스 함수 단에서 "이 구간은 크로스 엔트로피로, 저 구간은 MSE로 계산"** 하도록 구현하는 게 더 간편함

## 8. 챕터 전체 요약: 딥러닝 문제 풀이의 4단계

강의 전체를 관통하는 하나의 프레임워크:

| 단계 | 내용 |
|---|---|
| **1. 입출력(문제) 정의** | 어떤 데이터를 넣어서 어떤 출력을 얻고 싶은지 결정 (회귀? 분류? 멀티레이블?) — 입력·출력(레이블) 데이터를 모두 준비 |
| **2. 모델 구성** | MLP, CNN, RNN 등 데이터를 처리할 인공신경망 구조 설계 |
| **3. 로스 정의** | 문제 유형에 맞는 로스 함수 선택 (회귀→MSE, 이진분류→BCE, 다중분류→Cross Entropy가 일반적이지만 절대적인 법은 아님) |
| **4. 웨이트 최적화** | SGD, Momentum, RMSProp, Adam 등으로 그라디언트 디센트를 수행 |

> **로스를 정의한다는 것의 본질 = "레이블의 분포를 무엇으로 가정할 것인가"를 선택하는 것** (지난 강의에서 배운 MLE/NLL 관점)

- 다른 로스 함수를 선택해도 특별한 이유가 없다면 성능 차이가 크지 않은 경우가 많음 — 그러니 관례(회귀=MSE, 이진분류=BCE, 다중분류=CE)를 따르되, 그 이유를 이해하고 있는 것이 중요

## 9. 이번 강의 핵심 요약

- [x] 다중 분류는 클래스 개수만큼의 출력 노드가 필요하며, 레이블은 **원-핫 인코딩**으로 표현
- [x] **소프트맥스**: 여러 출력을 함께 사용해서 "합이 1, 모두 양수"인 확률 분포를 만들어주는 활성화 함수
- [x] 절댓값 기반 함수는 부호 구별을 못해 정보가 중복·낭비되는 문제가 있어 소프트맥스가 더 적합
- [x] 시그모이드는 각 클래스가 배타적이지 않은 **멀티레이블 분류**에 적합 (다중 분류와는 다른 문제)
- [x] 다중 분류의 로스는 **멀티누이 분포**를 가정한 NLL = **크로스 엔트로피**
- [x] 원-핫 인코딩 덕분에, 로스 계산 시 **정답 클래스에 해당하는 항만 남고 나머지는 소거됨** — 소프트맥스 덕분에 그 하나만 키워도 나머지는 자동으로 억제됨
- [x] 크로스 엔트로피는 항상 엔트로피 이상이며, 크로스 엔트로피를 줄이는 것은 출력 분포를 정답 분포에 가깝게 만드는 것과 같음
- [x] BCE는 Cross Entropy의 2-클래스 특수 사례임을 재확인
- [x] PyTorch의 `nn.CrossEntropyLoss`는 소프트맥스가 내장되어 있으므로, 모델에는 소프트맥스를 따로 넣지 않는 것이 관례
- [x] **딥러닝 문제 풀이의 4단계**: ① 입출력 정의 → ② 모델 구성 → ③ 로스 정의 → ④ 웨이트 최적화

## 용어 정리

| 용어 | 의미 |
|---|---|
| 원-핫 인코딩 (One-hot Encoding) | 정답 클래스만 1, 나머지는 0으로 표현하는 레이블 방식 |
| 소프트맥스 (Softmax) | 여러 출력값을 함께 사용해 합이 1인 확률 분포로 변환하는 활성화 함수 |
| 멀티레이블 분류 (Multi-label Classification) | 한 입력에 대해 여러 클래스가 동시에 참일 수 있는 분류 문제 |
| 멀티누이 분포 (Multinoulli / Categorical Distribution) | 베르누이 분포의 다중 클래스 확장판 |
| 크로스 엔트로피 (Cross Entropy) | 멀티누이 분포를 가정한 NLL — 다중 분류의 표준 로스 함수 |
| 엔트로피 (Entropy) | 크로스 엔트로피에서 Q 자리에 정답 분포(y) 자체를 대입한 값 — 크로스 엔트로피의 하한선 |
| 멀티노미얼 로지스틱 회귀 / 소프트맥스 회귀 | 로짓을 선형으로 구하고 소프트맥스+크로스엔트로피로 학습하는 다중 분류의 해석 방식 |
