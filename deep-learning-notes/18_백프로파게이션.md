# 18강. 백프로파게이션 (Backpropagation)

> 딥러닝 강의 18강 정리 노트

---

## 1. 왜 백프로파게이션이 필요한가?

- 그라디언트 디센트를 하려면 **로스를 모든 웨이트에 대해 편미분**한 그라디언트가 필요함
- 문제: **깊은 층(입력에 가까운 층)에 있는 웨이트**에 대한 미분을 구하는 게 상대적으로 까다로움
- 이걸 체계적으로 구하는 방법이 바로 **백프로파게이션**

> 코드로 짤 때는 PyTorch 같은 프레임워크가 자동으로 계산해주지만, **원리를 한 번은 이해하고 넘어가는 게 중요함** (Vanishing Gradient 같은 현상을 이해하는 데도 필요)

---

## 2. 핵심 도구: 체인룰 (Chain Rule, 합성함수의 미분법)

### 복습: 고등학교 때 배운 합성함수 미분

> **`(x+1)²`을 x로 미분하기**

- 본능적으로: `2(x+1) × 1` (겉미분 × 속미분)
- 이걸 **체인룰**로 다시 쓰면:
  - 중간 변수를 하나 도입: `t = x+1` 이라 하면, `(x+1)² = t²`
  - `d(t²)/dt = 2t`, `dt/dx = 1`
  - **`d(t²)/dx = d(t²)/dt × dt/dx = 2t × 1 = 2(x+1)`**

### 그림으로 이해하기

```
x  →  (x+1 만들기)  →  t = x+1  →  (제곱하기)  →  t²
```

- 각 화살표(과정)마다 "그 단계에서의 미분"을 구해서, 전부 곱해나가면 됨
- **"뒤에서부터 미분해서 곱해나가는 것"이 체인룰**

---

## 3. 인공신경망에 체인룰 적용하기: 표기 정의

### 간단한 신경망 예시 (2층)

```
입력(나0) → W1 곱하고 → 들1 → F1 통과 → 나1 → W2 곱하고 → 들2 → F2 통과 → 나2(=출력, ŷ)
```

- 입력값 자체를 **나0(나제로)**로 표기함 — "0번째 층의 활성화 출력"처럼 취급
- 그래서 **들t = 나(t-1) × Wt + ...** 형태로 항상 일관되게 표현됨 (예: `들1 = 나0×W1 + ...`, `들2 = 나1×W2 + ...`)

| 기호 | 의미 |
|---|---|
| 들t (pre-activation) | t번째 층에서 웨이트·바이어스를 거친 직후의 값 (활성화 함수 통과 전) |
| 나t (activation output) | 들t가 활성화 함수를 통과한 값 |
| Wt | t번째 층의 웨이트 |

### 로스 정의 (MSE, 출력이 2개인 경우, 데이터 1개 기준)

```
L = (ŷ1 - y1)² + (ŷ2 - y2)²
  = (나2_1 - y1)² + (나2_2 - y2)²
```

- 데이터가 여러 개면 그냥 시그마(합)만 붙이면 되므로, 데이터 1개 기준으로 설명해도 무방함

---

## 4. W2(마지막 층 웨이트)에 대한 미분 구하기

### 순전파(정방향) 흐름 확인

```
들2 = 나1 × W2 + (다른 항들, W2로 미분하면 다 사라짐)
나2 = F2(들2)
L = (나2 - y)² 형태
```

### 체인룰로 미분 경로 쓰기

> **L → 나2 → 들2 → W2** 순서로 거슬러 올라가며 곱해줌

```
∂L/∂W2 = (∂L/∂나2) × (∂나2/∂들2) × (∂들2/∂W2)
```

각 항을 하나씩 구하면:

| 항 | 계산 |
|---|---|
| `∂L/∂나2` | `2(나2 - y)` (로스를 나2로 미분한 것 — 기본적인 미분) |
| `∂나2/∂들2` | `F2'(들2)` (활성화 함수의 미분) |
| `∂들2/∂W2` | `나1` (들2 = 나1×W2 + ... 이므로 W2로 미분하면 나1만 남음) |

> **각 단계는 개별적으로 보면 전혀 어렵지 않은 미분들** — 체인룰의 장점은 복잡한 걸 쉬운 조각들로 쪼개준다는 것

---

## 5. W1(더 깊은 층 웨이트)에 대한 미분 구하기 — 여기서부터 진짜 까다로움

### 경로 파악하기

- W1은 **들1** 안에 들어있음 (`들1 = 나0 × W1 + ...`, 여기서 나0은 입력값)
- 그러므로 경로는: **L → 나2 → 들2 → 나1 → 들1 → W1**
  - 여기서 핵심: 들2에서 나1로 가는 이유는, **들2 = 나1×W2 + ...** 이므로 들2 안에 나1이 들어있기 때문 (W2가 아니라 나1을 타고 내려가야 함)

```
∂L/∂W1 = (∂L/∂나2) × (∂나2/∂들2) × (∂들2/∂나1) × (∂나1/∂들1) × (∂들1/∂W1)
```

### 주의: 이것만으로는 부족하다! (매우 중요한 포인트)

> **미분이란 "어떤 변수를 살짝 바꿨을 때, 최종 결과가 얼마나 바뀌는가"를 의미함**

- `들1`을 살짝 바꾸면 → `나1`이 바뀌고 → `들2`가 바뀌고 → `나2`가 바뀌고 → `L`이 바뀜 (여기까지는 앞서 쓴 경로와 일치)
- **하지만 여기서 끝이 아님**: `나1`이 바뀌면, 출력이 여러 개(`나2_1`, `나2_2`)라면 **각 출력에 영향을 주는 모든 경로**를 다 고려해야 함
  - 즉, `나1`에서 뻗어나가는 경로가 하나가 아니라 **여러 개**일 수 있음 (예: `나2_1`로 가는 경로 + `나2_2`로 가는 경로)

### 해결: 여러 경로(패스)를 모두 더해줘야 한다

> **여러 경로를 통해 영향을 미치는 경우, 각 경로별로 구한 미분을 전부 더해줘야 한다**

```
∂L/∂나1 = (경로1: 나2_1을 거쳐가는 미분) + (경로2: 나2_2를 거쳐가는 미분) + ...
```

- 이렇게 "여러 경로의 합"이 된다는 사실은 다변수 함수의 체인룰(전미분)에서 나오는 성질 — 자세한 증명은 생략하고 **결과(더해진다)를 받아들이면 됨**
- 이 합쳐진 값을 편의상 물결 기호 등으로 표기해서 사용

> **핵심 포인트: 그라디언트가 지나가는 경로(path)가 여러 개라면, 그 경로들에서 각각 구한 미분을 전부 더해줘야 한다**

---

## 6. 패턴 발견: "액웨 액웨 나"

### 표기 단순화

- **"액"** = 활성화 함수의 미분 (`F'`)
- **"웨"** = 웨이트를 곱하는 것 (`W`, 웨이트의 '웨')
- **"나"** = 마지막에 등장하는 `∂들/∂W` = 그 층으로 들어온 나(activation) 값

### 패턴 정리

| 미분 대상 | 패턴 |
|---|---|
| 마지막 층(W2)에 대한 미분 | `액 나` (활성화 미분 1번 + 마지막 항) |
| 그 전 층(W1)에 대한 미분 | `액웨 액 나` (활성화미분→웨이트→활성화미분→마지막항) |
| 그 전전 층(W0)에 대한 미분 | `액웨 액웨 액 나` (한 층씩 더해질 때마다 "액웨"가 하나씩 늘어남) |

> **결론: 층이 깊어질수록 "액웨"가 하나씩 추가되고, 맨 마지막은 항상 "액 나"로 끝난다**

- 이 패턴("액웨 액웨 ... 액 나")만 기억하면, 아무리 깊은 신경망이라도 그 구조를 통해 미분식을 쉽게 떠올릴 수 있음
- (여러 경로가 있는 경우엔 이 패턴으로 구한 값들을 경로별로 더해줘야 한다는 점도 함께 기억)

---

## 7. 포워드 프로파게이션이 필요한 이유

### 왜 그냥 그라디언트만 구하면 안 될까?

- 그라디언트 수식(`액웨 액웨 액 나`) 안에는 **들1, 나1, 들2, 나2** 같은 **실제 값**들이 들어있음
- 이 값들을 알아야 미분식에 **대입**해서 실제 숫자로 된 그라디언트를 구할 수 있음

### 그래서 필요한 2단계 과정

| 단계 | 하는 일 |
|---|---|
| **포워드 프로파게이션 (Forward Propagation)** | 입력을 넣어서 신경망을 순서대로 통과시키며, **들1, 나1, 들2, 나2** 등 중간값들을 전부 계산하고 저장 |
| **백프로파게이션 (Backpropagation)** | 저장해둔 값들을 이용해서, 뒤에서부터 앞으로 체인룰을 적용하며 **각 웨이트에 대한 편미분(그라디언트)**을 계산 |

> **정리: 포워드로 값을 채워놓고 → 백워드로 미분을 계산 → 그 그라디언트로 SGD/Adam 등을 적용해서 웨이트 업데이트**

---

## 8. 왜 이름이 "백프로파게이션"인가?

> **미분(그라디언트)이 출력 쪽에서 입력 쪽으로 "뒤로(back)" 전달(propagate)되면서 계산되기 때문**

---

## 9. 이번 강의 핵심 요약

- [x] 그라디언트 디센트를 위해서는 모든 웨이트에 대한 편미분이 필요하고, **깊은 층의 웨이트일수록 미분이 까다로움**
- [x] 핵심 도구는 **체인룰(합성함수의 미분법)** — 복잡한 미분을 여러 개의 쉬운 조각으로 쪼개서 곱함
- [x] 마지막 층(W2)의 미분: `∂L/∂나2 × ∂나2/∂들2 × ∂들2/∂W2` (경로 하나)
- [x] 더 깊은 층(W1)의 미분을 구할 때는, **출력이 여러 개라면 그 각각으로 가는 여러 경로를 모두 고려해서 더해줘야 함** (경로 파악 시 웨이트를 곱하는 표기는 "웨"임에 유의)
- [x] 패턴 요약: **"액웨 액웨 ... 액 나"** — 층이 깊어질수록 "액웨"가 하나씩 늘어나고, 마지막은 항상 "액 나"로 끝남
- [x] 실제 그라디언트를 계산하려면 **들, 나 같은 중간값들이 필요** → 그래서 먼저 **포워드 프로파게이션**으로 값을 계산·저장해두고, 그 다음 **백프로파게이션**으로 뒤에서부터 미분을 계산
- [x] "백프로파게이션"이라는 이름은 미분이 출력에서 입력 쪽으로 거꾸로 전달되기 때문에 붙여짐
- [x] 이 그라디언트를 구한 뒤 SGD/Adam 등의 업데이트 수식을 적용하는 것이 딥러닝 학습의 전체 흐름

---

## 용어 정리

| 용어 | 의미 |
|---|---|
| 체인룰 (Chain Rule) | 합성함수의 미분법 — 복잡한 미분을 여러 단계로 쪼개서 곱해 구하는 방법 |
| 들 (pre-activation) | 웨이트·바이어스를 거친 직후, 활성화 함수를 통과하기 전의 값 |
| 나 (activation output) | 들 값이 활성화 함수를 통과한 후의 값 |
| 백프로파게이션 (Backpropagation) | 출력에서 입력 방향으로 미분(그라디언트)을 거꾸로 전달하며 계산하는 과정 |
| 포워드 프로파게이션 (Forward Propagation) | 입력을 신경망에 순서대로 통과시켜 중간값들을 계산·저장하는 과정 |
| 경로(패스)의 합 | 한 변수가 여러 경로를 통해 최종 결과에 영향을 줄 때, 각 경로의 미분을 모두 더해야 하는 원리 |
