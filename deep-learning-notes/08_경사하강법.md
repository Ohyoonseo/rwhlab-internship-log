# 8강. 경사하강법 (Gradient Descent)

> 딥러닝 강의 8강 정리 노트

---

## 1. 왜 경사하강법이 필요한가?

- 이전 강의에서 배운 방법: `a, b`를 일일이 바꿔가며 로스를 계산하고 최소값을 찾는 **그리드 탐색**
- 파라미터가 2개(a, b)일 땐 가능했지만, **GPT-3처럼 파라미터가 1500억 개**면 절대 불가능
- → 더 스마트한 방법이 필요 = **경사하강법 (Gradient Descent)**

> **경사하강법은 딥러닝의 핵심(코어) 알고리즘**

---

## 2. 경사하강법의 핵심 아이디어

### 기본 발상
1. 처음 `a, b`를 **아무렇게나(랜덤하게)** 잡음
2. 현재 위치에서 **로스를 줄이는 방향**으로만 조금씩 이동
3. 이 과정을 반복하면 결국 최소 지점으로 수렴함

### 비유: 어두운 산에서 아래로 내려가기
- 전체 지형(모든 a, b 조합의 로스)을 다 볼 수는 없음
- 하지만 **지금 서 있는 위치에서 발밑을 더듬어보면, 어느 방향이 가장 가파르게 내려가는지는 알 수 있음**
- 그 방향으로 한 걸음 내딛고, 다시 그 자리에서 같은 과정을 반복
- → 전체 지형을 몰라도 결국 낮은 곳(최솟값)에 도달 가능

> 핵심: 모든 지점의 로스를 그릴 필요 없이, **현재 위치에서의 방향만 알면 됨**

---

## 3. 그라디언트(Gradient)란?

> **그라디언트 = 항상 가장 가파르게 올라가는 방향을 향하는 벡터**

### 계산 방법
- 함수의 각 변수에 대해 **편미분**을 구한 후, 벡터로 묶어줌
- 예: `f(x, y) = x² + y`
  - `x`로 편미분 → `2x`
  - `y`로 편미분 → `1`
  - 그라디언트 = `(2x, 1)`

### 그라디언트가 "가장 가파른 방향"이라는 것을 시각적으로 확인

- 예시 함수: `f(x, y) = x² + y²`
  - 그라디언트 = `(2x, 2y)`
- 위치 `(1, 1)`에서 그라디언트 계산 → `(2, 2)`
  - 이 벡터를 `(1,1)` 위치에 그려보면, `(3,3)` 방향(바깥쪽, 위로 퍼지는 방향)을 향함
  - → 실제로 `x²+y²` 함수가 가장 가파르게 **증가**하는 방향과 일치함

### 최솟값을 찾으려면?

> **그라디언트의 반대 방향으로 이동하면 됨** (가장 가파르게 감소하는 방향)

**예시로 확인**
```
1단계: (1,1)에서 시작 → 그라디언트 (2,2) → 반대방향 이동 → (-1,-1)
2단계: (-1,-1)에서 그라디언트 (-2,-2) → 반대방향 이동 → (1,1)
3단계: (1,1)에서 다시 그라디언트 (2,2) → 반대방향 → (-1,-1)
```
- 문제 발생: **(1,1)과 (-1,-1) 사이를 계속 왔다갔다(다리다리) 함** → 수렴하지 않음!

---

## 4. 러닝레이트 (Learning Rate)

### 문제의 원인
- 그라디언트는 **방향**은 정확하지만, **크기(길이)가 너무 큼**
- 그 크기 그대로 이동하면 목표를 지나쳐서 반대편으로 튕겨나가는 **진동(오버슈팅)** 현상 발생

### 해결책: 러닝레이트(α, alpha)

> **러닝레이트 = 그라디언트 방향으로 이동하는 보폭(step size)을 조절하는 값** (보통 0~1 사이)

**적용 예시** (α = 0.1)
```
(1,1)에서 그라디언트 (2,2) → 0.1 × (2,2) = (0.2, 0.2)만큼만 이동
→ (1,1) - (0.2,0.2) = (0.8, 0.8)
```
- 조금씩, 조금씩 이동 → 진동 없이 서서히 최솟값으로 **수렴**

### 왜 수렴 지점을 지나치지(overshoot) 않을까?

- 최솟값에 가까워질수록 **그라디언트의 크기(기울기) 자체가 점점 작아짐**
- 즉, 목표에 가까워질수록 보폭도 자동으로 점점 작아짐 → 자연스럽게 수렴

---

## 5. 경사하강법의 수식

현재 위치를 `(a_k, b_k)` (k번째 스텝)라고 하면:

```
1. 현재 위치에서 로스(Loss)를 a, b에 대해 각각 편미분 → 그라디언트 계산
2. 그라디언트에 a_k, b_k 값을 대입
3. 그 값에 러닝레이트(α)를 곱함
4. 현재 위치에서 그 값을 뺌 (반대 방향으로 이동)

a_{k+1} = a_k - α × (∂Loss/∂a at a_k, b_k)
b_{k+1} = b_k - α × (∂Loss/∂b at a_k, b_k)
```

> **이 수식이 바로 딥러닝에서 가장 중요한 수식 = Gradient Descent 식**

---

## 6. 초기 웨이트(Initial Weight)는 어떻게 잡을까?

- "아무렇게나 잡으세요"라고 했지만, **정말 아무렇게나 잡으면 너무 멀리 떨어져서 비효율적일 수 있음**
- 적절한 초기값 설정이 필요함
- 대표적인 연구자 3인(**르쿤(LeCun), 카이밍(Kaiming He), 자비어(Xavier/Glorot)**)이 공통적으로 제안한 방법:
  > **랜덤하게 초기화하되, 수학적 근거에 기반한 특정 분포에서 뽑아야 한다**
  - 세 방법 모두 "랜덤 초기화"라는 큰 방향은 같지만, **분산(variance)을 정하는 구체적인 전략이 조금씩 다름**

## 7. 경사하강법(Gradient Descent)의 단점

### 단점 ①: 너무 느리다 (모든 데이터를 다 고려하기 때문)

- 그라디언트를 구할 때, 로스 함수 안에 **모든 데이터가 다 포함**되어 있음
- 데이터가 5개면 문제없지만, **데이터가 5만 개, 5억 개**라면?
  - 한 번 업데이트(한 스텝)를 할 때마다 모든 데이터를 다 고려해서 미분을 계산해야 함
  - → 연산량이 어마어마하게 커서 **한 번 업데이트하는 데도 매우 오래 걸림**
- 장점처럼 보이지만("모든 데이터를 신중하게 고려") 실제로는 **너무 느려서 못 씀**

### 단점 ②: 로컬 미니멈(Local Minimum)에 빠질 수 있다

- 로스 함수가 항상 예쁜 밥그릇(포물선) 모양은 아님
- 실제로는 **여러 개의 움푹 패인 지점(구덩이)**이 존재할 수 있음

| 용어 | 의미 |
|---|---|
| **로컬 미니멈 (Local Minimum)** | 주변에서는 가장 낮지만, 전체적으로 봤을 때는 최저점이 아닌 지점 |
| **글로벌 미니멈 (Global Minimum)** | 전체 구간에서 진짜로 가장 낮은 지점 |

- 경사하강법은 **출발 지점에서 가장 가까운 로컬 미니멈**으로 갈 수밖에 없음
- 시작 위치에 따라 전혀 다른(더 나쁜) 로컬 미니멈에 빠질 수 있음
- **현재 존재하는 모든 딥러닝 방식도 글로벌 미니멈을 보장하지는 못함** — 그나마 "좋은" 로컬 미니멈을 찾는 게 목표

## 용어 정리

| 용어 | 의미 |
|---|---|
| 경사하강법 (Gradient Descent) | 그라디언트 반대 방향으로 조금씩 이동하며 최솟값을 찾는 알고리즘 |
| 그라디언트 (Gradient) | 각 변수에 대한 편미분을 벡터로 묶은 것, 가장 가파른 증가 방향을 가리킴 |
| 편미분 (Partial Derivative) | 여러 변수 중 하나에 대해서만 미분하는 것 |
| 러닝레이트 (Learning Rate, α) | 한 스텝에 이동하는 보폭을 조절하는 값 |
| 로컬 미니멈 (Local Minimum) | 주변 영역에서는 가장 낮지만 전체 최저점은 아닌 지점 |
| 글로벌 미니멈 (Global Minimum) | 전체 구간에서 진짜 가장 낮은 지점 |
| SGD (Stochastic Gradient Descent) | 경사하강법의 느림·로컬미니멈 문제를 완화한 확률적 경사하강법 (다음 강의) |
