# 14강. Adam (Adaptive Moment Estimation)

> 딥러닝 강의 14강 정리 노트

---

## 1. Adam이란?

> **Adam = Adaptive Moment Estimation**의 약자 (사람 이름이 아니라 약자!)

- **모멘텀(Momentum)**: 그라디언트 방향을 누적 (관성)
- **RMSProp**: 그라디언트 크기를 누적 (축별 보폭 조절)
- **Adam = 모멘텀 + RMSProp을 합친 것**

### 업데이트 수식의 큰 그림

```
분자: m̂ (모멘텀 반영 — 방향 누적)
분모: √v̂ + ε (RMSProp 반영 — 크기 누적)

W = W_이전 - α × m̂ / (√v̂ + ε)
```

- 기존 방식은 그냥 "현재 그라디언트"만 사용해서 업데이트했는데, Adam은 이 자리를 **"방향(m) ÷ 크기(v)"**로 바꾼 것

---

## 2. m (모멘텀 항) 직접 계산해보며 이해하기

### 수식 (베타1을 1/2로 놓고 간단히 계산)

```
m_t = β₁ × m_(t-1) + (1-β₁) × g_t
```
- `g_t` = t번째 시점의 그라디언트
- β₁, β₂는 0~1 사이 하이퍼파라미터 (설명 편의상 여기서는 **1/2**로 놓고 진행)

### t=0부터 직접 대입해보기

```
초기값: m₀ = 0, v₀ = 0

t=1: m₁ = (1/2)×m₀ + (1/2)×g₁ = (1/2)g₁

t=2: m₂ = (1/2)×m₁ + (1/2)×g₂
        = (1/2)×(1/2)g₁ + (1/2)g₂
        = (1/4)g₁ + (1/2)g₂

t=3: m₃ = (1/2)×m₂ + (1/2)×g₃
        = (1/8)g₁ + (1/4)g₂ + (1/2)g₃
```

### 이 계산이 보여주는 것

> **과거의 그라디언트일수록 계수가 점점 작아지면서(1/8, 1/4, 1/2...) 잊혀져 감**

- 가장 최근 그라디언트(`g₃`)의 비중이 가장 크고, 오래된 그라디언트(`g₁`)일수록 비중이 작아짐
- 비유: 버스가 급정거했을 때(관성이 확 생김) 그 관성이 30분 뒤에도 그대로 남아있지 않고, **시간이 지나면 서서히 원래대로 돌아오는 것**과 같은 원리

### 이런 방식의 이름: 지수 이동평균 (Exponential Moving Average)

- 과거 값을 지수적으로 감소시키면서 평균을 취해나가는 방식
- → **EMA (Exponential Moving Average)**라고 부름
- (용어 자체보다 "과거 그라디언트를 점점 잊으면서 누적한다"는 개념이 중요)

> **`m` 하나만 있고 분모가 없다면, 그게 바로 순수 모멘텀(Momentum) 알고리즘의 수식**

---

## 3. v (RMSProp 항) 이해하기

### 수식 (베타2도 1/2로 놓고 진행)

```
v_t = β₂ × v_(t-1) + (1-β₂) × g_t²
```

- **m과의 차이**: 그라디언트 `g_t`를 그대로 누적하는 게 아니라, **제곱(g_t²)한 값**을 누적함
- 여기서 제곱은 **엘리멘트-와이즈(element-wise) 제곱** — 그라디언트가 벡터이므로, 벡터 자체를 제곱할 순 없고 **각 성분(원소)마다 각각 제곱**한다는 뜻 (논문에서 이렇게 표기하기로 정의함)

### v를 사용해서 얻는 효과

- 그라디언트를 제곱해서 누적하니까 → 자연스럽게 **크기(부호 없는 절댓값 개념)를 누적**하게 됨
- 이 값(v)을 **분모**에 놓으면:
  - 지금까지 **적게 탐색된 축** (v가 작음) → 분모가 작음 → **더 크게 이동** (많이 탐색하도록 유도)
  - 지금까지 **많이 탐색된 축** (v가 큼) → 분모가 큼 → **더 작게 이동** (이미 충분히 봤으니 적게 이동)

> **`v`를 분모에 놓는 것 = RMSProp 알고리즘 반영**

- `m` ÷ `v`(제곱근) 형태로 결합하면 → **모멘텀(방향, 분자) + RMSProp(크기, 분모)** = **Adam**

---

## 4. 나누기/제곱은 전부 엘리멘트-와이즈(element-wise)

- Adam 수식에서 등장하는 제곱, 나누기는 **모두 벡터의 각 원소별로(element-wise)** 계산되는 것
- 즉, 각 웨이트(파라미터) 하나하나에 대해 개별적으로 편미분하고, 개별적으로 제곱하고, 개별적으로 나눠준다고 생각하면 이해하기 쉬움

---

## 5. m̂, v̂ (hat 붙은 버전): 왜 필요한가? — 편향 보정 (Bias Correction)

### 문제 상황: 초반에 m, v가 0에서 시작하는 문제

> **비유: 이동평균선(Moving Average)** — 주식에서 "5일선", "60일선"처럼 주가의 흐름을 부드럽게 만든 선

- 상장 첫날부터 이동평균을 구한다고 하면, 초반에는 데이터가 거의 없어서 이동평균이 **실제 값보다 0에 더 가깝게(왜곡되게)** 계산됨
- Adam의 `m`, `v`도 마찬가지: 초기값이 **0에서 시작**하기 때문에, 학습 초반에는 `m`, `v` 값이 실제보다 **작게(0 쪽으로 치우치게)** 계산되는 문제가 생김

### 해결책: hat(보정) 붙이기

- `m̂`, `v̂`는 이 초반의 "0으로 치우친 편향(bias)"을 보정해주는 버전
- 초반에는 분모 쪽으로 나눠주는 값을 조정해서 **m, v를 좀 더 키워주는 방식**으로 보정
- 시간이 지날수록(t가 커질수록) 이 보정 효과는 점점 옅어지고, 결국 원래 `m`, `v`와 비슷해짐

> 즉, **m̂, v̂ = 초반의 "0에 가깝게 왜곡된" 문제를 고쳐주는 보정된 버전의 m, v**

---

## 6. 입실론(ε)은 왜 필요한가?

### 역할 ①: 분모가 0에 가까워지는 것을 방지

- `v`(누적된 크기)가 너무 작아서 **0에 가까워지면**, 분모가 거의 0이 되어버림
- 분모가 0에 가까우면 → 그 값으로 나눈 결과가 **극단적으로 커져서 순간이동하듯 튀는 현상** 발생
- 예: 학습 시작 시점에 어떤 축이 아주 평평(그라디언트가 거의 0)했다면, 그 축의 v도 거의 0 → 이때 입실론이 없다면 분모가 0에 가까워져서 **비정상적으로 크게 튀어버릴 수 있음**
- → **입실론(작은 양수, 보통 `10⁻⁸` 정도)**을 분모에 더해줘서 이런 극단적 상황을 방지

### 역할 ② (강사의 추가 추측): 수렴 막바지의 안정성

- 학습이 거의 수렴할 즈음, 분자(m)보다 분모(v)가 더 빠르게 0으로 수렴하는 상황이 생길 수도 있음
- 이럴 때도 입실론이 없으면 분모가 너무 작아져서, 거의 다 수렴했는데 갑자기 툭 튀어버릴 위험이 있음
- 입실론이 이런 상황도 어느 정도 방지해주는 역할을 할 수 있다는 것이 강사의 개인적인 해석

## 7. 시각화로 비교: SGD vs Momentum vs RMSProp vs Adam

### 안장점(Saddle Point)에서의 차이

> **안장점(Saddle Point)**: 말안장처럼 생긴 지점 — 한쪽 방향으로는 최소, 다른 방향으로는 최대가 되는 지점. 이 지점에서는 여러 방향으로의 미분(그라디언트)이 0에 가까움

- **SGD**: 안장점에서 그라디언트가 거의 0이라서 **탈출을 잘 못함** (거의 멈춰버림)
- **모멘텀**: 과거의 관성 덕분에 앞으로 갔다 뒤로 갔다 하면서도 서서히 밀고 나가다가, 다른 방향의 그라디언트가 조금씩 쌓이면서 결국 안장점을 **탈출함**
- **RMSProp**: 시작하자마자 앞쪽이 너무 가파르면, 상대적으로 완만한 방향(옆쪽)으로 **휘어져서** 진행함

### 평평한 지점에서 출발했을 때의 차이

- **SGD**: 평평한 곳에서는 그라디언트가 거의 0이라 **거의 못 움직임**
- **모멘텀**: 앞으로 갔다가, 관성 때문에 옆으로 갔다가, 다시 반대로 오는 식으로 진동하며 서서히 나아감
- **RMSProp**: 평평한 곳에서는 분모(v)가 작으니 **한 번에 크게 튀어나감** (빠르게 벗어남)
  - 방향을 꺾을 때는 오히려 "여긴 가파르네" 하고 다시 조심스러워지는 모습도 보임
- **Adam**: 대체로 모멘텀과 RMSProp의 장점을 섞은 움직임을 보이며, 회전(방향 전환)도 유연하게 잘 처리함
  - 다만 수렴 막바지에 **살짝 "따닥"하고 튀는 모습**이 관찰되기도 함 (강사 추측: 입실론이 상대적으로 작게 설정된 경우, 분모가 급격히 작아지면서 순간적으로 크게 이동하는 현상일 수 있음)

---

## 8. 이번 강의 핵심 요약

- [x] **Adam = 모멘텀(방향 누적, 분자) + RMSProp(크기 누적, 분모)**
- [x] `m`: 그라디언트를 지수적으로 누적 (최근 것일수록 비중이 큼, 과거는 점점 잊혀짐 = 지수 이동평균)
- [x] `v`: 그라디언트의 **제곱(크기)**을 지수적으로 누적 → 축마다 다른 학습 속도 적용 (RMSProp 원리)
- [x] 제곱과 나누기는 모두 **엘리멘트-와이즈(원소별)** 연산
- [x] `m̂`, `v̂`: 초반에 `m`, `v`가 0에서 시작하는 편향을 보정한 버전 (Bias Correction)
- [x] **입실론(ε)**: 분모가 0에 너무 가까워져서 값이 비정상적으로 튀는 것을 방지
- [x] 안장점·평평한 지점 등 다양한 지형에서 SGD/모멘텀/RMSProp/Adam의 움직임 패턴이 서로 다름 — Adam이 대체로 가장 안정적이고 유연하게 수렴

---

## 용어 정리

| 용어 | 의미 |
|---|---|
| Adam (Adaptive Moment Estimation) | 모멘텀과 RMSProp을 결합한 최적화 알고리즘 |
| m (1차 모멘트) | 그라디언트의 지수 이동평균 — 방향(모멘텀) 반영 |
| v (2차 모멘트) | 그라디언트 제곱의 지수 이동평균 — 크기(RMSProp) 반영 |
| 지수 이동평균 (EMA) | 최근 값일수록 비중을 크게, 과거일수록 비중을 지수적으로 줄여가며 평균내는 방식 |
| 엘리멘트-와이즈 (Element-wise) | 벡터의 각 원소마다 개별적으로 연산을 적용하는 방식 |
| 편향 보정 (Bias Correction) | m, v가 초기(0)에서 시작해 생기는 편향을 보정하는 과정 (m̂, v̂) |
| 입실론 (ε) | 분모가 0에 가까워지는 것을 막기 위해 더해주는 아주 작은 양수 |
| 안장점 (Saddle Point) | 한쪽 방향으로는 최소, 다른 방향으로는 최대가 되는 지점 (여러 방향의 그라디언트가 0에 가까움) |
