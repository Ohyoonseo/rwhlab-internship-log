# 13강. RMSProp (Root Mean Square Propagation)

> 딥러닝 강의 13강 정리 노트

---

## 1. RMSProp이란?

> **RMSProp = Root Mean Square Propagation**

- **모멘텀(Momentum)**: 그라디언트의 **방향(부호 포함)**을 그대로 누적함
- **RMSProp**: 그라디언트의 **크기(제곱)**를 누적함

| 방식 | 누적하는 것 |
|---|---|
| 모멘텀 | 그라디언트 자체 (방향 포함) |
| RMSProp | 그라디언트의 **크기**(제곱) |

---

## 2. RMSProp이 풀고 싶은 문제

### 상황 설정: 웨이트가 2개(a, b)인 경우

- 어떤 지점에서 그라디언트가 극단적으로 `(a축: 0.1, b축: 10)` 처럼 나왔다고 가정
- 이 경우:
  - **a축으로는 거의 업데이트가 안 됨** (그라디언트가 작아서)
  - **b축으로만 엄청나게 많이 업데이트됨** (그라디언트가 커서)

> **이건 문제다!** 한쪽 축만 편중되게 이동하고, 다른 쪽 축은 거의 안 움직이게 됨

---

## 3. RMSProp의 해결 방식: 축마다 다르게 조절(평준화)

### 핵심 아이디어

> **그라디언트가 작은 축은 좀 더 키워주고, 그라디언트가 큰 축은 좀 줄여주자**

- 예: `(0.1, 10)` → 작은 쪽(0.1)은 키우고, 큰 쪽(10)은 줄여서 → `(1, 1)`에 가깝게 **평준화**
- 결과적으로 **a축, b축 둘 다 골고루 적당히 이동**하게 됨

### 러닝레이트를 축마다 다르게 주는 셈

- 기존 방식: 모든 축에 **동일한 러닝레이트(α)**를 곱함
- RMSProp: 그라디언트 크기에 따라 **각 축마다 실질적으로 다른 러닝레이트를 적용한 효과**를 만듦
  - 그라디언트가 작은(완만한) 축 → 실질적으로 **러닝레이트를 키운 셈** (예: ×10)
  - 그라디언트가 큰(가파른) 축 → 실질적으로 **러닝레이트를 줄인 셈** (예: ×0.1)

---

## 4. 왜 "가파른 곳은 조심, 완만한 곳은 과감하게"가 좋은 전략인가?

### 직관적 해석

| 그라디언트 크기 | 지형의 성격 | RMSProp의 대응 |
|---|---|---|
| **크다 (가파르다)** | 리스크가 있는 지형 (좁고 깊게 팬 웅덩이일 수 있음) | **조심조심** 이동 (보폭 줄임) |
| **작다 (완만하다)** | 평평한 지형 | **과감하게** 이동 (보폭 키움) |

### 비유: 등산/하산

- **가파른 쪽**: 등산화 신고 급경사를 빠르게 내려가면 위험함 — 여기가 정말 좋은 곳인지 모르는데 그라디언트만 믿고 확 갔다가는 **이상한 좁은 웅덩이(로컬 미니멈)에 갇혀버릴 위험**이 있음 → 조심스럽게 접근
- **완만한 쪽**: 완만하게 떨어지는 지형이 오히려 더 안정적으로 수렴할 수 있는 좋은 지점일 가능성이 높음 → 그런 방향은 신뢰하고 잘 밟아가도록 함

> 즉, "급격하게 팬 곳"보다 "완만하게 잘 이어지는 곳"이 더 좋은 해(solution)일 가능성이 높다는 암묵적 가정이 깔려 있음

### 평평한 곳에서 빨리 탈출하기

- 그라디언트가 **작다 = 완만하다 = 평평하다**
- 평평한 구간은 **그쪽으로 많이 이동해도 로스(loss)가 별로 안 바뀌는 구간**
- 즉, 그 지점에 계속 머물러봐야 별로 재미(=개선)가 없으니까 **빠르게 벗어나서** 더 좋은 곳을 찾아보자는 전략

### 만약 그냥 기본 Gradient Descent였다면?

- 평평한 지점에서는 그라디언트가 거의 0
- → 업데이트가 거의 일어나지 않아서 **그 자리에 계속 머무르게 됨** (정체)
- RMSProp을 쓰면 평평한 구간에서도 **빠르게 탈출해서 더 좋은 지점을 찾아갈 수 있음**

---

## 5. 다음 예고: Adam (모멘텀 + RMSProp)

- 지금까지 배운 **모멘텀(방향의 누적)**과 **RMSProp(크기의 누적)**을 합친 알고리즘이 바로 **Adam**
- **Adam = Adaptive Moment Estimation**의 약자
  - (강사도 처음엔 "아담"이라는 이름 자체가 고유명사인 줄 알았다가, 알고 보니 약자였다고 언급)

---

## 6. 이번 강의 핵심 요약

- [x] **RMSProp**: 그라디언트의 **크기(제곱)**를 누적해서, 각 축(웨이트)마다 실질적인 러닝레이트를 다르게 적용
- [x] 목표: 한쪽 축만 과도하게 업데이트되고 다른 축은 거의 안 되는 **불균형을 평준화**
- [x] **그라디언트가 큰(가파른) 축**: 보폭을 줄여서 조심스럽게 이동 (리스크 있는 좁은 웅덩이일 수 있음)
- [x] **그라디언트가 작은(완만한) 축**: 보폭을 키워서 과감하게 이동 (평평한 곳에서 빨리 벗어나 더 좋은 곳 탐색)
- [x] 기본 Gradient Descent는 평평한 곳에서 그라디언트가 0이라 정체되지만, RMSProp은 그런 구간에서도 빠르게 탈출 가능
- [x] **모멘텀 + RMSProp = Adam (Adaptive Moment Estimation)** — 다음 강의에서 다룰 예정

---

## 용어 정리

| 용어 | 의미 |
|---|---|
| RMSProp (Root Mean Square Propagation) | 그라디언트 크기(제곱)를 누적해서 축마다 학습 속도를 조절하는 최적화 기법 |
| 평준화 (Balancing) | 그라디언트가 큰 축은 줄이고, 작은 축은 키워서 균형을 맞추는 것 |
| Adam (Adaptive Moment Estimation) | 모멘텀(방향 누적) + RMSProp(크기 누적)을 결합한 최적화 알고리즘 |
